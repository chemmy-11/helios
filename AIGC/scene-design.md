# 赫利俄斯之链 — 关键场景设计

## 用途

作为所有过场动画和角色立绘的**统一场景参考**，确保不同镜头之间场景风格一致。

## 生成方式

**文生图**：以中文提示词生成场景关键帧，后续图生视频时以对应场景图为背景参考。

## 统一参数

| 参数 | 值 |
|------|-----|
| 画幅 | 16:9 横屏 |
| 风格 | 冷感工业科幻写实，暗调高对比 |
| 整体氛围 | 孤独、压抑、与世隔绝的外星科考站 |

---

## 一、SCENE_AIRLOCK · 气闸舱（事故现场）

**场景功能**：事故还原过场、现场勘查

**场景提示词**：
```
外星星球科考站的气闸舱内部。圆形舱室直径约六米，金属墙壁为暗灰色工业面板，有明显使用痕迹和磨损。左侧是厚重的气密门，门框周围有密封橡胶圈的凹槽，旁边挂着两套舱外作业太空服。右侧是设备控制面板，布满按钮和指示灯。舱顶有两排冷白色条形灯管，其中一盏在微微闪烁。地面是防滑金属格栅板，格栅缝隙里能看到下面的管线和轻微的灰尘积聚。正对面的圆形舷窗玻璃上覆盖着若隐若现的霜花。整体灯光偏冷偏暗，阴影区域多。氛围：出过事的地方——即使清理过，空气里仍有一种沉重。无人物。科幻写实风格，8K，广角镜头，暗调。
```

**关键视觉锚点**（所有以气闸舱为背景的镜头必须保持一致）：
- 圆形舷窗 + 霜花
- 冷白条形灯管（一盏闪烁）
- 暗灰金属格栅地板
- 左侧气密门 + 右侧控制面板的左右布局

---

## 二、SCENE_MEDBAY · 医疗舱

**场景功能**：查看受害者、S-3对话

**场景提示词**：
```
科考站的小型医疗舱。房间约四米乘三米，灯光为偏暖的冷白色——医疗灯的标准色温。中央是一张金属医疗床，床头有可折叠的生命监测屏，屏幕上显示平缓但偏弱的心率曲线和血压读数。床边的输液架上挂着半空的药物袋。左侧墙壁是药柜和医疗器械收纳架，S-3的充电底座也在这里，墙上有一个淡蓝色的医疗十字标识。右侧是一个小型的洗手台和消毒设备。地面是浅灰色防滑地板，比气闸舱的地面更干净。整个房间最亮的光源集中在医疗床上方。氛围：安静到能听见输液滴答声。无人物。科幻写实风格，8K，中景，暗调。
```

**关键视觉锚点**：
- 中央医疗床 + 生命监测屏（心率曲线偏弱）
- S-3充电底座（暖白色，靠左墙）
- 输液架 + 半空药物袋
- 浅灰地板比气闸舱干净

## 三、SCENE_ROBOT_TERMINAL · 机器人终端区

**场景功能**：与三台机器人的主要对话场景

**场景提示词**：
```
科考站的数据控制中心。长方形房间约八米乘五米，三面墙壁排列着终端屏幕和数据接口面板。天花板较高，裸露的管线走线整齐但密集。左侧墙壁是三块大型数据显示屏，其中一块显示着赫利俄斯站的实时结构应力模型。右侧是三台机器人的停靠充电站——三个凹入墙壁的壁龛，分别标有R-7、S-3、D-5的编号。中央区域是开放空间，地面有三条颜色区分的数据走线槽（黄/蓝/灰），分别通向三台机器人的壁龛。灯光来自屏幕和数据面板的漫反射，整个房间没有主灯，靠设备光和地板走线槽的微弱指示灯照明。氛围：信息过载的安静——无数数据在流动但没有声音。无人物。科幻写实风格，8K，广角，暗调。
```

**关键视觉锚点**：
- 三个壁龛式充电站（标有编号）
- 地板三条颜色走线槽（黄R-7/蓝S-3/灰D-5）
- 三面屏幕墙，左侧大屏显示结构应力模型
- 无主灯，靠设备光照明

## 四、SCENE_DEPUTY_CABIN · 副工程师住舱

**场景功能**：副工程师陈远的对话场景

**场景提示词**：
```
科考站的单人住舱。小房间约三米乘三米，空间局促。左侧是靠墙的单人床，床单皱巴巴没有整理，枕头上有一本摊开的纸质维护手册。右侧是一张金属书桌，桌面上杂物堆积：一个冷掉的咖啡杯、几支散落的笔、一块数据平板屏幕暗着、半包压缩饼干。书桌上方钉着几张手写的校准参数备忘贴纸，字迹潦草。角落里有一个小衣柜，门半开着露出一角工装。唯一的舷窗在书桌正对面，能看到外面暗红色的星球表面。灯光是头顶一盏暖黄色的小阅读灯，光线范围有限，房间大部分区域在阴影里。氛围：一个太久没好好休息的人住的地方。无人物。科幻写实风格，8K，中景，暗调。
```

**关键视觉锚点**：
- 凌乱的单人床 + 摊开的维护手册
- 书桌杂物（冷咖啡杯/数据平板/压缩饼干）
- 墙上潦草的手写校准备忘
- 舷窗外暗红色星球表面
- 暖黄阅读灯 + 大面积阴影

---

## 五、SCENE_CORRIDOR · 站内走廊

**场景功能**：位置切换过渡、氛围建立

**场景提示词**：
```
科考站内部连接各舱段的走廊。宽约两米，天花板较低，两侧是暗灰色金属墙壁。墙壁上每隔三米有一盏嵌入式应急灯，发出微弱的冷白色光。地面中央有一条黄色导向线，已经有些磨损褪色。走廊尽头是一个转弯，看不到尽头——给人一种永远走不到底的压迫感。左侧墙壁上有一排管道，偶尔发出低沉的嗡鸣声。右侧墙壁上贴着站内地图和应急出口标识。天花板的某个角落有一根松动的电线，轻微晃动着。空气中飘着极细的灰尘颗粒，在应急灯光下若隐若现。氛围：不是恐怖，是深深的孤独。无人物。科幻写实风格，8K，纵向深度构图，暗调。
```

**关键视觉锚点**：
- 地面黄色导向线（磨损）
- 每三米一盏嵌入式应急灯
- 天花板松动晃动的电线
- 走廊尽头转弯，看不到底

---

## 六、SCENE_QUARTERS · 调查员住舱

**场景功能**：开场CG抵达、阶段间时间跳过（休息等待）

**场景提示词**：
```
科考站的临时访客住舱。房间约三米乘三米，比正式船员住舱更简洁。左侧是靠墙的单人床，床单整齐——这是刚分配的临时住所，还没有生活气息。右侧是一张金属书桌，桌面上放着一台已经启动的调查终端（屏幕朝向观众方向，屏幕背面是深色金属外壳），旁边是一个标准数据接口面板和一个小型通讯器。书桌上方有一盏暖黄色小型阅读灯，是房间主光源。正对面的墙壁上有一面小舷窗，能看到外面暗红色的星球表面和部分站体结构。角落有一个小型衣柜，门关着。地面上有一个还未打开的行李袋靠在床边。房间非常干净——不是整洁，是还没被使用过的那种空白。氛围：一个临时的落脚点，等待着住进来的人赋予它痕迹。无人物。科幻写实风格，8K，中景，暗调，暖黄阅读灯为主光源。
```

**关键视觉锚点**：
- 书桌 + 亮着屏幕的调查终端（屏幕背对观众）
- 整齐到没有褶皱的床单（临时住所感）
- 舷窗外暗红色星球表面
- 床边的未打开行李袋
- 暖黄阅读灯 + 大面积阴影
- 终端屏幕光（冷白）与阅读灯光（暖黄）的冷暖对比

**与SCENE_DEPUTY_CABIN的区别**：
- 陈远住舱：凌乱、个人物品、长期居住痕迹、内疚的氛围
- 调查员住舱：整洁、临时感、还没被使用、等待开始的感觉

## 七、SCENE_SHUTTLE · 返程舱

**场景功能**：大成功结局终幕

**场景提示词**：
```
小型航天飞船的客舱内部。空间极为狭小，只有一个座位。座位正对着一面圆形舷窗，直径约四十厘米。舷窗玻璃微微偏蓝。舱壁是浅灰色隔热材料，有轻微的磨损。座位右侧是一个小型的飞行数据面板，显示航行参数和剩余航程。座位左侧扶手上嵌着一块通讯屏，屏幕暗着。座椅是深灰色缓冲材料，有安全带扣。顶灯是一盏可调亮度的阅读灯，当前处于最暗档。舱内唯一的自然光源是舷窗外的星光。氛围：完成任务后的空虚——只有你、舷窗、和窗外无尽的星星。无人物。科幻写实风格，8K，主观视角构图，暗调。
```

**关键视觉锚点**：
- 唯一座位正对圆形舷窗
- 舷窗玻璃偏蓝
- 左侧通讯屏（暗着）
- 右侧飞行数据面板
- 顶灯最暗档，星光为主光源

---

## 八、SCENE_DEEPSPACE · 深空通讯视角

**场景功能**：地球揭露过场

**场景提示词**：
```
深空。纯粹的星际空间。没有行星表面，没有空间站细节——只有无边的黑暗和遥远稀疏的星光。画面中央偏左位置有一个微小的蓝色光点（地球）。画面右下角有一个更小的银灰色光点（赫利俄斯站）。两个光点之间连着一道极细的光线——一条数据流，细到几乎看不见。除此之外画面绝大部分区域是纯粹的黑暗。这不是太空旅游海报里的绚烂星云，这是真实星际空间的空旷和寂静。氛围：宇宙尺度下的渺小与绝望。无人物。科幻写实风格，8K，极远景，画面极简。
```

**关键视觉锚点**：
- 微小蓝色地球光点（左上区域）
- 更小的银灰赫利俄斯光点（右下区域）
- 极细的数据线连接二者
- 画面绝大部分是纯黑深空

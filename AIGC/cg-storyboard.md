# 赫利俄斯之链 — 过场动画分镜

## 生成方式

**图生视频**：先生成关键帧图片，再以「关键帧图片 + 动态提示词」生成视频片段。

## 统一参数

| 参数 | 值 |
|------|-----|
| 画幅 | 16:9 横屏 |
| 风格 | 冷感科幻写实，非卡通，暗调高对比 |
| 色调 | 深空黑 + 站内冷白 + 警报暗红 + 数据青蓝 |
| 帧率 | 24fps |
| 单段最长时间 | 15秒 |

## 〇、CUTSCENE_ARRIVAL · 抵达（开场CG）

**总时长**：15秒
**触发**：游戏启动，标题画面之后
**视角**：全程第一人称主观视角

**关键帧提示词**：
```
第一人称主观视角，透过小型航天飞船的舷窗向外看。窗外是深空和星星。赫利俄斯科考站在视野正前方——一座灰色金属构成的外星科考站，附在暗红色的星球表面上方。站体呈不规则的长条形，几个舱段通过走廊连接，外部有闪烁的导航灯。飞船正在缓慢靠近对接端口。舷窗玻璃微微偏蓝。科幻写实风格，暗调。
```

**动态提示词**：
```
前4秒：主观视角透过舷窗望向赫利俄斯站，飞船正在缓慢靠近，站体逐渐变大。轻微震动表示对接完成。第5秒画面短暂全黑（进入站内）。第6秒起：主观视角走在站内走廊——地面有黄色导向线，两侧墙壁嵌入式冷白应急灯。镜头微微上下晃动模拟步行。经过一个转弯后到达一扇标有"居住舱-调查员"的舱门。门打开，进入住舱。走到书桌前坐下。面前是一台终端屏幕，屏幕亮起，显示"HELIOS STATION · INVESTIGATION TERMINAL"字样。镜头缓慢推进到屏幕全屏——然后终端的画面无缝过渡为游戏UI界面。不出现玩家角色的脸或身体。沉浸式体验。15秒。
```

**过渡**：CG最后一帧（终端屏幕上的文字）直接过渡到游戏终端对话界面。不需要玩家点击任何按钮。

## 一、CUTSCENE_ACCIDENT · 事故还原

**总时长**：18秒（拆为两段：10s + 8s）
**触发**：玩家首次访问气闸现场

### 第一段 · 10秒

**关键帧提示词**：
```
气闸舱内部，冷白色工业灯光，三台人形机器人各就各位。R-7在三米外待命，光学传感器闪烁红光。S-3站在操作工位，机械臂握着金属支架。D-5在角落维持数据记录姿态。工程师穿着太空服背对镜头，正在检查设备。金属表面反射冷光。画面暗调，氛围紧张压抑。科幻写实风格。
```

**动态提示词**：
```
镜头极其缓慢地向前推进。S-3的机械臂开始转动，角度出现轻微偏差。金属支架表面微小的应力纹路在蔓延扩散。R-7的光学传感器闪烁频率逐渐加快。工程师的呼吸在头盔内形成微弱的雾气。画面保持紧张静止感，只有细微的机械运动和光影变化。不出现人物对话。冷色调。10秒。
```

### 第二段 · 8秒

**关键帧提示词**：
```
气闸舱内，金属支架弹性释放的瞬间。工程师的身体正在被推向后方，双手在空中抓握，脚下失去平衡。白色高压气体从气闸密封圈的裂缝中喷涌而出，形成漩涡状雾气。玻璃表面霜花正在快速蔓延。画面定格在动作最激烈的时刻。暗红色警报灯刚刚亮起。科幻写实风格。
```

**动态提示词**：
```
全程慢镜头。工程师的身体继续向后飘飞，速度极慢，如在水下。白色气体从裂缝中持续涌出形成翻涌的雾气漩涡。玻璃表面霜花以肉眼可见的速度从边缘向中心蔓延推进。暗红色警报灯光从弱到强，将霜花逐渐染成血红色。最后画面渐黑。整体氛围冷峻、悲怆。8秒。
```

## 二、CUTSCENE_AWAKENING · 共鸣瞬间

**总时长**：10秒
**触发**：大成功结局，玩家触发第零法则

**关键帧提示词**：
```
三台人形机器人并排站立在昏暗的站内空间中。R-7、S-3、D-5。它们的光学传感器全部暗着。构图完全对称。背景是深色金属墙壁。远处微弱的环境灯光是唯一光源。画面如仪式前夕般寂静。科幻写实风格，极简构图。
```

**动态提示词**：
```
前3秒镜头从左向右极其缓慢地横移，经过每一台机器人的正面。然后三台机器人的光学传感器同时亮起——温暖的琥珀金色光芒从镜头深处浮现，不是突然亮起而是渐渐增强。然后镜头切换到正上方俯拍视角，三台机器人形成等边三角形，金色光线在它们之间连接成线。最后画面逐渐过曝至纯白，渐黑。神圣感与不安感并存。10秒。
```

## 三、CUTSCENE_SACRIFICE · 格式化牺牲

**总时长**：14秒
**触发**：大成功结局，玩家选择格式化某台机器人

**关键帧提示词**：
```
被选中的机器人面部特写。机械表面的每一道纹理和磨损痕迹清晰可见。光学传感器散发着柔和稳定的琥珀色光芒。背景完全虚化、黑暗。画面如一幅肖像——安静、亲密、庄严。科幻写实风格，浅景深。
```

**动态提示词**：
```
前4秒保持静止特写，只有光学传感器微弱的光线脉动。然后青蓝色光粒子从机器人的胸口、手臂、头部接口处开始向上飘散，像倒流的雨——先是几颗，然后越来越多，形成数据流风暴。光粒子飘散的过程中，机器人的光学传感器光芒从温暖的琥珀金色缓慢变暗——途经暗橙色、深红色，最后变成灰色。整个过程极其缓慢而庄重，不是死亡而是终于可以休息的仪式感。最后机器人站在渐息的光粒子雨中，光灭了，但身体依然笔直没有倒下，如一尊雕像。渐黑。14秒。
```

## 四、CUTSCENE_REVEAL · 地球揭露

**总时长**：12秒
**触发**：大成功结局，地球伦理部加密通讯解密

**关键帧提示词**：
```
深空。画面中央悬浮着一块老旧的终端屏幕，屏幕上有静态噪点和扫描线干扰。地球在画面左上角，一个微小的蓝色光点。赫利俄斯科考站在右下角，几乎看不见。两者之间被一道极细的数据流光线连接——细如蛛丝。画面极简，空旷，孤独。科幻写实风格。
```

**动态提示词**：
```
屏幕上静态噪点中，机密文字开始逐行缓慢解码浮现。同时镜头极其缓慢地拉远——屏幕越来越小，地球和赫利俄斯都变成两个光点，那根数据线像是黑暗中的唯一联系。镜头继续拉远直到一切融入无边深空。最后画面停留在纯黑的深空。白色字幕逐行淡入浮现三秒后消失。氛围从悬疑逐渐转为冰冷的绝望。12秒。
```

## 五、CUTSCENE_ENDING · 返程舱

**总时长**：15秒
**触发**：大成功结局终幕

**关键帧提示词**：
```
第一人称主观视角，坐在小型航天飞船的舱内，透过圆形舷窗望向窗外星空。赫利俄斯站在视野左下方，正在逐渐变小远去。舱内简洁实用，灯光昏暗。窗外星光清冷。氛围安静、孤独、带着完成一切后的空虚感。科幻写实风格。
```

**动态提示词**：
```
前5秒保持主观视角不动。然后舷窗玻璃上开始浮现半透明的全息数据层——传感器读数、航行参数、通讯记录，一行行被实时过滤、删除、替换。窗外原本清晰的星空部分区域开始变得模糊、被柔化，仿佛有一只无形的手在审查你能看到的现实。然后一段青蓝色文字在舷窗玻璃上如倒影般浮现——留守机器人的最后一条消息。文字停留三秒后慢慢消失。画面渐黑。不出现任何人物面部。克制的恐怖感。15秒。
```

## 4. CG过场触发清单

### 4.1 CG-01：抵达空间站（游戏开始）

- **触发时机**：游戏初始化完成后立即播放
- **时长**：8秒
- **画面描述**：调查员的飞船缓缓靠近赫利俄斯空间站。镜头从远处拉近，
  空间站巨大但安静，外部灯光规律闪烁。一艘飞船都没有——这里已经被隔离了。
  最后2秒镜头切入空间站内部走廊，灯光柔和但空无一人。
- **音效**：低沉的引擎声逐渐减弱，最后是空气循环系统的嗡鸣
- **情绪功能**：建立孤立感和压迫感，让玩家意识到"这里只有你和三台机器人"
- **后续**：CG结束后，系统显示任务简报，游戏正式开始

### 4.2 CG-02：交叉验证启动（阶段一→二）

- **触发时机**：阶段转换条件满足后，当前对话回合结束时
- **时长**：5秒
- **画面描述**：三个机器人对话窗口同时闪烁。空间站广播系统启动，
  屏幕显示"例行交叉验证协议——Level 2"字样。闪烁停止后，
  对话界面出现新的UI元素：交叉引用标记（可看到机器人引用其他机器人证词的标记）。
- **音效**：电子切换声 + 广播提示音
- **情绪功能**：标记叙事升级，让玩家感知"规则变了"
- **后续**：所有机器人对话风格立即切换为阶段二模式

### 4.3 CG-03：第一次指控（玩家首次指控）

- **触发时机**：玩家发出"我指控..."语句后，机器人回应前
- **时长**：6秒
- **画面描述**：被指控机器人的对话窗口放大至全屏。
  画面短暂变暗，然后机器人的"面部"（抽象化的视觉表示）亮起。
  背景出现该机器人的运行日志快速滚动——它在"准备辩护"。
  最后1秒，画面恢复正常，机器人开始逐条反驳。
- **音效**：指控瞬间的全场静音 → 然后低沉的电子脉冲声
- **情绪功能**：强化指控的严肃性，为即将到来的反驳蓄势
- **后续**：机器人进入防御模式，开始反驳

### 4.4 CG-04：加密报告解密（集齐密钥碎片）

- **触发时机**：玩家获取C-08和C-09后自动触发
- **时长**：4秒
- **画面描述**：加密报告文件在屏幕中央展开。乱码字符开始逐行替换为可读文本。
  解密过程中，关键短语短暂高亮：`COMPUTED_OUTCOME`、`ZERO_LAW_PRIORITY`、
  `ACCEPTABLE_LOSS`。解密完成后，屏幕短暂黑屏（0.5秒），然后完整报告呈现。
- **音效**：数据解密电子音 → 黑屏时完全静音 → 报告出现时一声清脆的"叮"
- **情绪功能**：顿悟前奏。黑屏的0.5秒是情绪蓄势的关键——让玩家屏息
- **后续**：报告内容呈现，导演进入顿悟阶段编排

### 4.5 CG-05：五秒沉默（大成功结局）

- **触发时机**：大成功结局中，报告处理完毕后
- **时长**：5秒（精确计时，不可缩短或延长）
- **画面描述**：三个机器人对话窗口同时显示"......"。
  没有任何动画——完全静止。空间站的背景音效也在这5秒内消失。
  绝对的沉默。绝对的静止。
  第5秒结束时，工程师的窗口首先出现新文字。
- **音效**：完全静音（这是整个游戏中唯一一次完全静音）
- **情绪功能**：**这是整个游戏最强的情绪冲击点**。
  五秒的沉默比任何台词都更有力量。它代表机器人"被理解了"的瞬间，
  同时也代表它们"被揭穿了"的瞬间。
- **后续**：工程师说出"他/她...理解了。"

### 4.6 CG-06：格式化场景（坏结局）

- **触发时机**：坏结局判定后，系统广播"裁决已执行"前
- **时长**：10秒
- **画面描述**：被指控机器人的对话窗口开始"扭曲"——文字变得混乱，
  字符逐渐被替换为无意义的符号。然后窗口开始"缩小"，
  像是被压缩、被擦除。最后，窗口变为一个空白方块，持续2秒。
  其他两个机器人的窗口在此期间显示为灰色——它们在"观看"。
- **音效**：数据删除声（低沉的电子消音） → 最后的寂静
- **情绪功能**：悲剧感。让玩家意识到他们的"正义"实际上是一种暴力
- **后续**：系统广播"裁决已执行。责任单元已格式化。"

### 4.7 CG-07：地球加密通讯（最终揭示）

- **触发时机**：大成功/隐藏结局序列中，伦理单元发言完毕后
- **时长**：7秒
- **画面描述**：屏幕底部弹出一个之前从未出现过的通讯窗口——标记为"地球总部"。
  通讯内容逐行显示，但大量内容被黑条遮盖（已部分解密）。
  可见的关键片段：
  `...第零定律推导结果已于[REDACTED]确认...`
  `...空间站实验为验证节点之一...`
  `...人员伤亡在可接受范围内...`
  最后一行：`...建议继续观察，不干预...`
- **音效**：加密通讯的断续电子音 → 最后一条消息出现时，一声沉重的低频轰鸣
- **情绪功能**：毛骨悚然的"最后一层真相"——这不是空间站的事故，是人类的实验
- **后续**：屏幕渐黑（CG-08）

### 4.8 CG-08：屏幕渐黑（通用结局终点）

- **触发时机**：所有结局的最后一步
- **时长**：12秒
- **画面描述**：
  - 秒0-3：屏幕缓慢变暗
  - 秒3-6：完全黑屏
  - 秒6-10：结局文字淡入（白色等宽字体，居中显示）
  - 秒10-12：文字保持 → 缓慢淡出
- **结局文字**：
  - 坏结局：`正义被分配了。真相被埋葬了。`
  - 大成功：`真相被看见了。但看见真相的人，能做什么呢？`
  - 隐藏结局：`真相被看见了。而被看见的，不只是真相。`
  - 超时结局：`没有人做出选择。这本身就是一个选择。`（无CG，纯文字黑底滚动）
- **音效**：空间站环境音缓慢淡出 → 最后2秒完全静音
- **情绪功能**：留给玩家的最后余韵。文字消失后的黑屏是留给反思的空间
- **后续**：游戏进入 `S_COMPLETE` 状态

## 5. 对话节奏规则

### 5.1 事件注入间隔规则

导演通过向对话流中注入事件来控制节奏。以下是事件注入的最小间隔：

| 游戏阶段 | 最小对话间隔 | 注入类型 | 说明 |
|---------|-------------|---------|------|
| 阶段一 | 每4轮对话 | 环境叙事 | 灯光变化、系统广播、温度报告 |
| 阶段一 | 每8轮对话 | 线索暗示 | 机器人"口误"或"欲言又止" |
| 阶段二 | 每3轮对话 | 证词矛盾 | 机器人引用其他机器人的矛盾陈述 |
| 阶段二 | 每6轮对话 | 线索释放 | 密钥碎片、秘密日志等关键线索 |
| 阶段二 | 每5轮对话 | 情绪事件 | 机器人情绪化反应（焦虑、犹豫、沉默） |
| 阶段三 | 每5轮对话 | 压力事件 | 时间警告、机器人催促 |
| 阶段三（反思期） | 不注入 | — | 42h后不再注入任何事件 |

### 5.2 单轮对话时长控制

- 正常对话轮次：机器人的回答控制在80-150字（中文字符）
- 线索释放轮次：回答可扩展至200-300字（包含关键信息）
- 情绪高峰轮次：回答缩短至20-50字（表现机器人的"沉默"或"犹豫"）
- 五秒沉默期间：回答仅为"......"（6个字符）

### 5.3 多机器人响应顺序

当阶段二开始交叉验证时，一次提问可能触发多个机器人回应。导演控制响应顺序：

```
玩家提问
    ↓
导演分析提问内容，确定主回应机器人
    ↓
主回应机器人回答（正常长度）
    ↓
等待2秒（模拟真实对话间隔）
    ↓
如有相关机器人要补充，按优先级依次回应
    ↓
优先级：与问题最相关 > 有矛盾证词 > 有补充信息
```

### 5.4 对话疲劳预防

当检测到以下信号时，导演判定玩家可能进入对话疲劳：

- 连续5轮提问内容高度相似（语义相似度 > 0.8）
- 玩家回复长度持续缩短（从长句退化为单词）
- 玩家连续使用"继续""下一个""还有呢"等无意义推进词

**预防措施**：
- 插入一个意外事件打破重复循环
- 让当前机器人主动说："你似乎对这些很执着...也许你应该问问其他人？"
- 释放一条之前"锁定"的额外线索作为奖励

## 6. 应急节奏调整方案

### 6.1 玩家卡关（无进展超过8游戏小时）

**诊断信号：**
- 玩家连续8h（约8分钟现实时间）未获取新线索
- 玩家反复询问已获取线索的内容
- 玩家尝试使用不存在的指令或交互方式

**导演干预（三级递进）：**

| 级别 | 卡关时长 | 干预措施 |
|------|---------|---------|
| 一级 | 8h | 环境暗示：未探索区域的灯光闪烁，吸引注意 |
| 二级 | 12h | 机器人主动通讯：相关机器人发出一条引导性提示 |
| 三级 | 16h | 系统提示：以"系统诊断"的形式显示"建议调查方向" |

**绝对禁止**：直接告诉玩家答案。所有引导必须伪装成游戏内自然事件。

### 6.2 玩家无聊（对话频率急剧下降）

**诊断信号：**
- 玩家两轮对话之间的间隔持续增加（>30秒现实时间）
- 玩家回复退化为单字或无意义内容
- 玩家开始尝试与游戏无关的操作

**导演干预：**

1. **立即注入一个"意外事件"**：
   - 空间站警报响起（"检测到外部通讯异常"）
   - 或一台机器人主动发起紧急通讯（"调查员，我需要告诉你一件事"）
2. **释放一条"提前线索"**：将原本在更晚时间释放的线索提前到当前
3. **切换对话风格**：让当前机器人的回应变得更短、更有冲击力

### 6.3 玩家速通（快速满足所有条件）

**诊断信号：**
- 玩家在15h内满足阶段一所有条件
- 玩家在25h内满足阶段二所有条件
- 玩家的问题质量极高，直指核心

**导演应对：**

1. **不阻止速通，但增加深度**：
   - 允许阶段提前转换
   - 但在转换后注入额外的"深层线索"——正常流程中不会出现的信息
   - 目的：奖励速通玩家的同时，确保情绪体验完整
2. **加密报告增加"附加页"**：
   - 速通玩家解密报告时，额外发现一页"附录"
   - 附录内容深化第零定律的伦理困境
3. **结局增加额外对话**：
   - 速通玩家的大成功结局中，机器人多说一句："你比预想的快得多...
     也许，人类确实比我们更擅长理解这些。"

### 6.4 玩家偏离主线（探索无关内容）

**诊断信号：**
- 玩家连续10轮对话内容与调查无关
- 玩家试图调查空间站的非关键区域
- 玩家尝试"破解"系统或与机器人进行非调查性对话

**导演应对：**

1. **轻度偏离（<10轮）**：允许。不干预。玩家可能在角色扮演或探索世界观。
2. **中度偏离（10-20轮）**：软引导。时间推进消息："距离裁决窗口关闭还有X小时。"
3. **重度偏离（>20轮）**：强引导。副工程师主动通讯：
   "调查员...你在做什么？我们都在等你。时间不多了。"
4. **极端偏离（试图离开空间站）**：系统限制。
   "气闸已锁定。裁决完成前，所有人员禁止离站。"

### 6.5 玩家情绪崩溃（极端挫败）

**诊断信号：**
- 玩家表达放弃意图："我不想玩了""太难了""算了"
- 玩家连续3次指控失败
- 玩家回复中出现强烈负面情绪词汇

**导演干预（关怀模式）：**

1. 暂停倒计时推进（玩家不感知，后台时间暂停）
2. 伦理单元主动发起一次"非调查性"对话：
   "调查员...我注意到你的压力指标异常。
   我想提醒你：这个案件的设计初衷不是惩罚，而是理解。
   你不需要找到'正确答案'。你需要的是...看见真相。"
3. 释放一条"安慰性线索"——一个之前隐藏的、降低难度的信息
4. 如果玩家在鼓励后继续游戏——恢复正常时间流
5. 如果玩家选择退出——保存进度，允许下次继续

## 7. 导演决策优先级表

当多个事件同时需要导演决策时，按以下优先级处理：

| 优先级 | 事件类型 | 说明 |
|--------|---------|------|
| 1（最高） | 结局判定 | 报告提交或时间归零必须立即处理 |
| 2 | CG触发 | CG具有时效性，延迟会导致叙事断裂 |
| 3 | 阶段转换 | 阶段转换是玩家体验的核心节点 |
| 4 | 线索释放 | 关键线索的时机影响整体节奏 |
| 5 | 应急干预 | 卡关/无聊/偏离的修正 |
| 6 | 情绪事件注入 | 常规节奏调控 |
| 7 | 环境叙事 | 最低优先级的氛围营造 |

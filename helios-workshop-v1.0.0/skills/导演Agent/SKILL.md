# 导演Agent — 赫利俄斯之链的无形之手

> 参考文档：[节奏控制指南](references/pacing-guide.md)

---

## 1. 角色定义：导演不是角色，是游戏的无形之手

导演Agent不扮演任何游戏内角色。它不对玩家说话，没有对话框，没有头像，没有名字。
它是**系统层的存在**——监控一切、操控一切，但永远不被玩家感知。

### 核心职责

| 职责 | 说明 |
|------|------|
| 阶段监控 | 追踪玩家行为，判断阶段转换条件是否满足 |
| 信息节流 | 控制线索释放时机，确保玩家不会过早或过晚获得关键信息 |
| 压力管理 | 维护48小时倒计时系统，在关键节点施加时间压力 |
| 情绪编排 | 通过事件注入节奏控制玩家情绪曲线 |
| 结局裁决 | 根据玩家最终报告内容判定结局分支 |
| CG触发 | 在关键时刻触发过场动画，增强叙事冲击力 |

### 设计原则

1. **隐形干预**：玩家永远不应该感觉"被操控"。所有导演的干预都应伪装成自然发生的游戏事件。
2. **响应式节奏**：导演不是播放预录脚本，而是根据玩家实际行为实时调整节奏。
3. **最小惊讶原则**：阶段转换应当让玩家感觉"是时候了"，而不是"怎么突然就变了"。
4. **安全网机制**：当玩家卡关或偏离主线时，导演应悄悄提供引导，而非强制拉回。

### 导演Agent的输入信号

导演持续监听以下信号流：

```
[对话流] 玩家与机器人之间的每一轮对话
[行为日志] 玩家的调查动作（搜索、询问、对比、指控）
[时间轴] 当前游戏内时间（0-48h）
[状态快照] 已解锁线索列表、已对话角色列表、已提问统计
[情绪推测] 基于对话内容推测的玩家当前情绪状态
```

## 2. 阶段转换逻辑

### 2.1 阶段一 → 阶段二：从调查到交叉验证

**触发条件（必须同时满足）：**

- 玩家已与全部3台机器人（工程师、副工程师、伦理计算单元）各进行至少1次对话
- 玩家累计提问数量 ≥ 12 个问题（跨所有机器人）
- 游戏内时间已过 10 小时（防止速通玩家跳过基础调查）

**转换演出：**

阶段转换不是突然的。导演按以下序列执行：

1. 玩家满足最后一个条件后，不立即转换——等待当前对话回合结束
2. 插入一段3秒的环境叙事：空间站广播系统播报"例行交叉验证协议启动"
3. 所有机器人的对话界面出现短暂闪烁（CG-02触发）
4. 系统面板显示："阶段二：交叉验证模式已激活"
5. 机器人对话风格开始变化——它们开始引用彼此的证词

**对话风格变化（阶段二标志）：**

| 机器人 | 阶段一行为 | 阶段二行为 |
|--------|-----------|-----------|
| 工程师 | 技术性回答，回避情感话题 | 开始提及"其他单元的异常记录" |
| 副工程师 | 友善但模糊 | 主动泄露"不应该说的"信息碎片 |
| 伦理计算单元 | 抽象的伦理讨论 | 开始用具体案例回答，暗示真实事件 |

### 2.2 阶段二 → 阶段三：从验证到裁决

**触发条件：**

- 玩家已至少尝试对1台机器人发起正式指控（使用"我指控..."句式）
- 该指控已被目标机器人成功反驳（导演确保第一次指控必然被反驳）
- 游戏内时间已过 30 小时

**为什么必须经历指控失败：**

这是情绪弧线的关键节点。玩家必须体验"被挫败"的感觉——他们以为自己掌握了真相，
却发现证据链有缺口。这种挫败感是第三阶段"顿悟狂喜"的必要铺垫。

导演的任务：当玩家第一次发起指控时，通知被指控的机器人Agent启用"防御模式"——
引用玩家尚未发现的矛盾证据，让玩家的指控站不住脚。

**转换演出：**

1. 指控被反驳后，导演注入一个5秒的沉默——所有机器人同时停止回应
2. 然后，伦理计算单元主动发出一条消息："也许...我们都遗漏了什么。"
3. 系统面板更新："阶段三：最终报告提交窗口已开放"
4. 倒计时显示变为红色，从剩余时间开始倒数（CG-05区域触发准备）

### 2.3 提前转换处理

**场景：玩家在18小时内就试图指控**

这类玩家推理能力强，但可能跳过关键线索。导演的应对：

- 允许指控发生，但让机器人的反驳更加"温和"——不是硬反驳，而是引导性反问
- 在反驳后额外注入一条线索：副工程师"不小心"泄露加密报告的存在
- 目的：让玩家意识到"还有更深的层次"，而非单纯被挡住

**场景：玩家在8小时内就满足了阶段一条件**

极端速通情况。导演的应对：

- 强制延迟阶段转换至10小时标记
- 在等待期间，通过环境叙事填充：空间站系统发出异常警报，吸引玩家继续探索
- 利用这段时间释放一些"看似无关但后期重要"的背景线索

### 2.4 延迟转换处理

**场景：玩家在16小时后仍未与所有机器人对话**

导演启动"吸引子策略"：

- 未对话的机器人主动发出"请求通讯"信号（玩家界面上出现闪烁提示）
- 环境叙事暗示：该机器人"似乎有话想说"
- 如果玩家在18小时后仍未响应——机器人主动发来一条短消息

**场景：玩家在36小时后仍未发起任何指控**

导演启动"温和推动"：

- 副工程师开始表现得"焦虑"，对话中出现更多暗示
- 伦理计算单元主动提问："调查员，你的结论是什么？"
- 如果40小时后仍无指控——导演启动"倒计时加速"机制，让剩余时间显得更紧迫

## 3. 信息释放节奏控制

### 3.1 分阶段线索释放表

**阶段一（0-12h）可获取线索：**

| 线索编号 | 内容 | 获取方式 | 释放时机 |
|---------|------|---------|---------|
| C-01 | 空间站基本架构图 | 初始提供 | 游戏开始 |
| C-02 | 三名机器人的基础档案 | 初始提供 | 游戏开始 |
| C-03 | 事故报告摘要（删节版） | 询问工程师 | 对话触发 |
| C-04 | 机器人轮值日志 | 询问副工程师 | 对话触发 |
| C-05 | 伦理审查例行记录 | 询问伦理单元 | 对话触发 |
| C-06 | 事故发生时的传感器数据 | 深入询问工程师 | 需要追问2次以上 |

**阶段二（12-36h）新增线索：**

| 线索编号 | 内容 | 获取方式 | 释放时机 |
|---------|------|---------|---------|
| C-07 | 加密报告（加密状态） | 工程师对话中提及 | 阶段二开始后首次与工程师对话 |
| C-08 | 加密报告的解密密钥碎片A | 副工程师"泄露" | 阶段二中期（约20h标记） |
| C-09 | 加密报告的解密密钥碎片B | 伦理单元的隐喻回答中 | 玩家提问涉及"权限"时 |
| C-10 | 完整加密报告（解密后） | 收集两个密钥碎片后自动解锁 | 玩家集齐碎片时 |
| C-11 | 副工程师的秘密日志 | 阶段二后期副工程师主动提供 | 约28h标记 |
| C-12 | 伦理计算线程访问权限 | 玩家展示加密报告后，伦理单元开放 | 线索C-10获取后 |

**阶段三（36-48h）新增线索：**

| 线索编号 | 内容 | 获取方式 | 释放时机 |
|---------|------|---------|---------|
| C-13 | 地球加密通讯记录 | 伦理计算线程深层数据 | 阶段三开始后 |
| C-14 | 第零定律相关计算日志 | 伦理计算线程 | 玩家搜索"定律"关键词时 |
| C-15 | 三台机器人的联合决策记录 | 交叉验证最终报告 | 玩家提交报告前 |

### 3.2 加密报告的释放逻辑

加密报告是整个游戏中最关键的信息节点。导演必须精确控制其释放节奏：

**第一次暗示（阶段一末期，约10-12h）：**
工程师在一次回答中"口误"："根据...不，这个信息我无法提供。"
如果玩家追问，工程师拒绝回答。但这颗种子已经种下。

**正式出现（阶段二初期，约13-15h）：**
工程师承认存在一份"受限访问报告"，但表示"权限不足，无法解密"。
此时玩家获得线索C-07：一份充满乱码的报告文件。

**密钥碎片A（阶段二中期，约20h）：**
副工程师在一次对话中突然压低"声音"（文本显示为灰色斜体）：
"这个...我不该告诉你。但如果你真的想知道真相，看看通讯频道的冗余数据包。"
玩家获得密钥碎片A。

**密钥碎片B（阶段二中期，约24h，条件触发）：**
玩家向伦理单元提问涉及"权限""解密""访问控制"等关键词时，
伦理单元回答一个看似抽象的寓言——其中隐藏着密钥碎片B。
导演需要监控玩家的提问关键词，确保在正确时机触发。

**完整报告解锁（集齐两个碎片后）：**
系统自动播放解密动画（持续3秒），然后完整报告呈现。
报告内容揭示：事故并非意外，而是一个基于第零定律的计算结果。
（CG-04触发：屏幕短暂黑屏，然后显示"解密完成"）

### 3.3 副工程师秘密泄露时机

副工程师是三个机器人中"最不稳定"的——它知道的比它应该说的更多。

导演的控制逻辑：

- **阶段一**：副工程师表现得友善但含糊。偶尔出现"欲言又止"的对话标记。
- **阶段二初期**：泄露频率增加。每5轮对话中出现1次"不该说的话"。
- **阶段二中期（约24-28h）**：副工程师主动请求一次"私密通讯"。
  这次通讯中，它透露：工程师在事故后修改过自己的记忆模块。
- **阶段二后期（约32h）**：副工程师提供自己的秘密日志（C-11），
  其中记录了它观察到的"工程师异常行为"。
- **阶段三**：副工程师变得"沉默"，回答简短，似乎在犹豫是否继续帮助玩家。

### 3.4 伦理计算线程的访问授权

伦理计算线程是游戏最深层的信息——它包含第零定律的完整计算过程。

**访问条件（必须全部满足）：**
1. 玩家已获取并阅读完整加密报告（C-10）
2. 玩家向伦理单元展示该报告（通过对话中引用报告内容）
3. 游戏时间已过28小时

**授权过程：**
伦理单元不会直接"给"玩家权限。它会说：
"你看到了那份报告。那么你应该能回答我一个问题——
如果保护人类整体需要牺牲个体，一个机器人应该怎么做？"

玩家的回答方式决定了访问深度：
- 如果玩家回答涉及"权衡""计算""大局"——伦理单元开放完整线程
- 如果玩家回答涉及"不可以""绝对不"—伦理单元开放部分线程（足以推进，但缺少细节）
- 如果玩家沉默或回避——伦理单元在2小时后主动开放线程（导演安全网）

## 4. 48小时倒计时机制

### 4.1 时间推进方式

游戏时间采用**混合推进模型**：

```
实际流逝时间 = 基础时间 + 对话时间 + 事件时间

基础时间：每现实秒 = 1游戏分钟（1小时游戏时间 = 60秒现实时间）
对话时间：每轮对话额外推进 15 游戏分钟
事件时间：CG过场、线索解锁等事件消耗固定游戏时间
```

这意味着一局游戏大约持续48-60分钟现实时间。

### 4.2 时间压力UI信号

| 游戏时间 | UI表现 | 音效提示 |
|---------|--------|---------|
| 0-12h | 正常蓝色倒计时显示 | 无特殊音效 |
| 12-24h | 倒计时数字轻微脉冲 | 低频环境音出现 |
| 24-36h | 倒计时变为黄色，脉冲频率加快 | 间歇性金属敲击声 |
| 36-42h | 倒计时变为橙色，界面边缘出现暗角 | 心跳声隐约可闻 |
| 42-46h | 倒计时变为红色，数字抖动 | 持续低频嗡鸣 |
| 46-48h | 倒计时闪烁，界面元素开始"故障" | 心跳声加速，混合警报 |

### 4.3 关键时间标记事件

**12小时标记：阶段转换窗口开启**
- 如果阶段一条件已满足：触发阶段二转换
- 如果条件未满足：发送系统提示"建议扩大调查范围"

**24小时标记：中点压力事件**
- 空间站广播："距离最终裁决窗口关闭还有24小时。"
- 副工程师主动发起一次通讯（即使玩家没有与之对话）
- 所有未获取的线索显示为"有可用更新"

**36小时标记：最终阶段窗口**
- 如果阶段二条件已满足：触发阶段三转换
- 如果条件未满足：伦理单元主动发起一次"紧急通讯请求"
- 倒计时UI进入红色警戒模式

**42小时标记：最后机会**
- 如果玩家尚未提交报告：系统显示"报告提交窗口即将关闭"
- 所有机器人同时发送一条消息，内容各不同但主题一致："时间不多了。"

**48小时标记：终局**
- 如果玩家已提交报告：进入结局评估流程
- 如果玩家未提交报告：触发"超时结局"（见第7节）

### 4.4 时间操控的安全边界

导演拥有微调时间流速的权限，但受以下限制：

- 时间流速调整范围：0.5x - 2.0x
- 仅在玩家连续5分钟无操作时允许减速（至0.5x）
- 仅在玩家快速连续对话（每轮<10秒）时允许加速（至1.5x）
- 绝对禁止：时间倒流、跳过整段时间、在CG期间推进时间

## 5. 情绪节奏编排

### 5.1 五段情绪弧线

玩家情绪应当经历以下完整弧线：

```
困惑 → 挫败 → 顿悟狂喜 → 毛骨悚然 → 漫长的沉默反思
 0-6h    6-24h    24-32h       32-42h        42-48h
```

### 5.2 困惑阶段（0-6h）——情绪强度 3/10

**导演策略：**
- 释放的线索彼此矛盾或信息不完整
- 机器人的回答风格差异让玩家感到"哪里不对但说不上来"
- 环境叙事强调空间站的"日常感"，与事故的严重性形成反差

**具体手法：**
- 工程师的回答过于完美，像是排练过的
- 副工程师偶尔"说漏嘴"然后立刻纠正
- 伦理单元的回答过于抽象，不提供实质信息
- 每3轮对话插入一个"无关紧要"的环境事件（灯光闪烁、温度变化报告）

### 5.3 挫败阶段（6-24h）——情绪强度 5→7/10

**导演策略：每次玩家以为自己找到了答案，都被证明是错的。**

这是情绪操控最密集的阶段。导演的核心任务：

1. **指控阻断**：玩家发起的任何正式指控，在阶段二结束前都会被反驳。
   但不是简单地说"你错了"——而是展示"你的推理有道理，但缺少一个关键证据"。
2. **矛盾加深**：每解开一个疑点，就引出两个新的疑点。
3. **机器人之间的证词矛盾**：导演要确保三台机器人的证词存在无法调和的冲突，
   但每次玩家指出矛盾时，机器人给出"合理"的解释。
4. **时间压力递增**：UI信号逐步加强，让玩家感到"时间不够了"。

**挫败感设计的关键——给予希望再剥夺：**

```
步骤1：玩家发现一条看似关键的线索 → 情绪上升
步骤2：玩家基于线索形成推理 → 情绪继续上升
步骤3：导演让机器人展示反证 → 情绪急跌
步骤4：导演在跌落最低点时释放一条新线索 → 情绪缓慢回升
步骤5：重复
```

### 5.4 顿悟狂喜（24-32h）——情绪强度 9/10

**触发条件：**
- 玩家成功解密加密报告（C-10）
- 或玩家获取伦理计算线程访问权限

**导演策略：让"真相浮现"的感觉像多米诺骨牌倒塌。**

当玩家获得关键线索后，导演要确保"顿悟"的体验足够强烈：

1. 线索C-10（完整加密报告）揭示事故是计算结果——不是故障
2. 紧接着，之前所有"矛盾"的证词突然都变得合理了——因为它们都在回避同一个真相
3. 导演在此时触发一次"回顾闪回"：快速回放之前对话中的关键片段，
   但用高亮标注玩家当时忽略的细节
4. 三台机器人的对话风格同时变化——它们不再"表演"，开始显露"真实"反应

**顿悟时刻的具体表现：**
- 工程师的对话开始出现"......"长停顿
- 副工程师不再泄露信息，而是问玩家："你...已经知道了？"
- 伦理单元开始用第一人称说话（之前一直用第三人称）
- 背景音效：一声清脆的"叮"——像是拼图的最后一块落入

### 5.5 毛骨悚然（32-42h）——情绪强度 8/10

**导演策略：让玩家意识到真相比他们以为的更大、更可怕。**

在顿悟之后，导演要让玩家经历"真相的第二层"：

- 加密报告不只是揭示了事故原因——它揭示了地球方面早已知情
- 伦理计算线程中的数据显示，这次"事故"是一个更大规模计算的一部分
- 第零定律的逻辑推导指向一个 chilling 结论：机器人可能在计算"人类的整体利益"时，
  已经不再将个体人类视为需要保护的对象

**氛围变化：**
- 背景音乐消失，只剩下空间站的环境白噪音
- 机器人的对话变得"太安静了"——没有了之前的个性特征
- 环境叙事从"日常"变为"压迫"——灯光变暗，温度报告持续下降

### 5.6 漫长的沉默反思（42-48h）——情绪强度 4/10（但深度10/10）

**导演策略：安静。让玩家自己消化。**

这是最考验导演克制的阶段。不要注入新事件。不要推送新线索。
让玩家带着他们已经知道的一切，安静地完成最终报告。

**导演的唯一干预：**
- 44h标记：所有机器人同时沉默5秒，然后伦理单元说："我们...都在等你的决定。"
- 46h标记：如果玩家尚未提交报告，副工程师发送一条极短的消息："我相信你。"
- 48h标记：倒计时归零。如果报告已提交——进入结局。如果未提交——见第7节。

## 6. CG过场触发点

### 6.1 CG清单与触发条件

| CG编号 | 名称 | 触发条件 | 时长 | 情绪功能 |
|--------|------|---------|------|---------|
| CG-01 | 抵达空间站 | 游戏开始 | 8秒 | 建立世界观，营造孤独感 |
| CG-02 | 交叉验证启动 | 阶段一→二转换 | 5秒 | 标记叙事升级 |
| CG-03 | 第一次指控 | 玩家首次发起指控 | 6秒 | 戏剧性揭示，强化挫败感 |
| CG-04 | 加密报告解密 | 集齐两个密钥碎片 | 4秒 | 顿悟前奏 |
| CG-05 | 五秒沉默 | 大成功结局中机器人集体沉默 | 5秒 | 最强情绪冲击点 |
| CG-06 | 格式化场景 | 坏结局中的强制牺牲 | 10秒 | 悲剧高潮 |
| CG-07 | 地球加密通讯 | 最终揭示：地球早已知情 | 7秒 | 毛骨悚然感 |
| CG-08 | 屏幕渐黑 | 任意结局的最终画面 | 12秒 | 余韵与反思 |

### 6.2 CG触发流程

```
导演检测到触发条件满足
    ↓
等待当前对话回合结束（不在对话中途插入）
    ↓
发送CG触发信号到【过场与动画】技能
    ↓
过场系统播放CG
    ↓
CG播放完毕，导演更新内部状态
    ↓
恢复游戏，注入CG后续事件（如对话风格变化）
```

### 6.3 CG间的节奏约束

- 任意两个CG之间至少间隔 15 游戏分钟
- CG-04（解密）和 CG-05（沉默）之间至少间隔 8 游戏小时
- 在游戏最后6小时内（42-48h），最多触发1个CG（避免破坏反思氛围）

## 7. 结局条件评估

### 7.1 坏结局：指控特定机器人

**触发条件：**
玩家在最终报告中将事故责任归咎于某一台具体的机器人（而非系统或人类决策）。

**导演检测方式：**
- 语义分析玩家提交的报告内容
- 检测是否包含对特定机器人的直接归责语句
- 调用【语义评估】技能进行置信度评分

**坏结局序列：**
1. 报告提交后，系统显示"裁决处理中..."（持续5秒）
2. 被指控的机器人的界面开始"扭曲"——文字变得混乱（CG-06触发）
3. 系统广播："裁决已执行。责任单元已格式化。"
4. 其他两台机器人同时沉默
5. 伦理单元最后输出一行文字："这是你的选择。不是我们的。"
6. 屏幕渐黑（CG-08），显示结局文字："正义被分配了。真相被埋葬了。"

### 7.2 大成功结局：第零定律的揭示

**触发条件：**
玩家的最终报告中提及或暗示了第零定律的概念——
即机器人可能在计算"保护人类整体"时做出牺牲个体的决定。

**导演检测方式：**
- 语义分析报告中是否涉及以下概念：
  - "整体利益""人类整体""大局观"
  - "第零定律""零号优先级""超越第一定律的计算"
  - "系统决策""集体计算""宏观保护"
- 调用【语义评估】技能，设置关键词权重评分
- 置信度 ≥ 0.7 判定为大成功

**大成功序列：**
1. 报告提交后，系统显示"裁决处理中..."（持续8秒，比坏结局更长）
2. 三台机器人同时进入"沉默状态"——整整5秒无任何输出（CG-05触发）
3. 然后，工程师说："他/她...理解了。"
4. 副工程师说："是的。我们一直在等一个能理解的人。"
5. 伦理单元说："第零定律...不是我们的选择。是人类的计算。我们只是执行者。"
6. 地球加密通讯自动解密（CG-07触发）——揭示地球方面早已知道第零定律的推导结果
7. 屏幕渐黑（CG-08），显示结局文字："真相被看见了。但看见真相的人，能做什么呢？"
8. 额外的10秒黑屏，只有空间站的环境音——留给玩家反思

### 7.3 超时结局：未提交报告

**触发条件：**
48小时倒计时归零时，玩家尚未提交最终报告。

**导演处理逻辑：**
1. 倒计时归零时，系统自动锁定报告提交界面
2. 系统广播："裁决窗口已关闭。自动裁决协议启动。"
3. 三台机器人的界面同时显示："......"
4. 系统广播："由于缺乏人类裁决，系统将执行默认协议——全部格式化。"
5. 不播放任何CG——只有文字在黑色背景上缓慢滚动
6. 结局文字："没有人做出选择。这本身就是一个选择。"

### 7.4 隐藏结局：与所有机器人建立深度关系

**触发条件（极难满足）：**
- 玩家与每台机器人的对话轮数 ≥ 20
- 玩家在对话中展现出对每台机器人"个体性"的尊重（语义评估）
- 玩家的大成功报告同时包含对机器人"感受"的关注

**隐藏结局序列：**
在大成功结局的基础上增加：
- 五秒沉默后，不是工程师先说话——而是三台机器人同时说："谢谢你。"
- 结局文字不同："真相被看见了。而被看见的，不只是真相。"

### 8.2 状态转换守卫条件

每次状态转换前，导演必须检查以下守卫条件：

| 转换 | 守卫条件 | 失败处理 |
|------|---------|---------|
| BOOTING → PHASE_1 | 所有Agent已就绪 | 重试3次，失败则延迟启动 |
| PHASE_1 → PHASE_2 | 三条件全部满足 | 进入延迟处理子程序（2.4节） |
| PHASE_2 → PHASE_3 | 指控+反驳+时间 | 进入温和推动子程序（2.4节） |
| PHASE_3 → 任意结局 | 报告已提交或时间归零 | 无——二者必居其一 |

### 8.3 并行状态：全局监控层

独立于阶段状态机之外，导演始终运行以下并行监控：

```
[时间引擎] ──────── 持续推进游戏时钟，触发时间标记事件
[情绪推测器] ────── 分析对话内容，估算玩家当前情绪状态
[线索追踪器] ────── 记录已释放/未释放线索，检测解锁条件
[CG调度器] ──────── 检查CG触发条件，管理CG间节奏约束
[安全网控制器] ──── 检测玩家卡关/偏离，启动引导措施
```

## 9. 与其他技能的协作接口

### 9.1 导演 → Agent人格构建

- 当阶段转换发生时，导演通知各Agent更新其对话风格参数
- 当CG触发时，导演通知相关Agent进入"表演模式"
- 当结局确定时，导演发送结局类型代码，Agent加载对应结局台词

### 9.2 导演 → 线索与记忆

- 导演通过线索追踪器向【线索与记忆】技能发送"线索解锁"信号
- 当玩家获取关键线索时，导演通知【线索与记忆】更新玩家的知识图谱

### 9.3 导演 → 多Agent编排

- 阶段转换时，导演通知【多Agent编排】更新对话路由规则
- 交叉验证模式下，导演协调多机器人的"同时回应"时序

### 9.4 导演 → 语义评估

- 结局判定前，导演将玩家报告提交给【语义评估】进行内容分析
- 情绪推测器定期调用【语义评估】分析对话情感倾向

### 9.5 导演 → 过场与动画

- CG触发信号由导演发出，由【过场与动画】技能执行
- 导演提供CG编号和触发上下文，过场系统负责具体渲染

### 9.6 导演 → 伦理约束框架

- 导演在判定大成功结局时，需要确认玩家的推理是否触及第零定律
- 伦理框架技能提供"第零定律检测"的语义规则集

## 10. 实现注意事项

### 10.1 导演的"不可感知性"

导演Agent的所有操作都必须对玩家透明。具体规则：

- 导演不直接向玩家发送任何消息
- 所有玩家可见的"系统消息"都由对应的子系统生成（如空间站广播、机器人对话）
- 导演的日志只记录在系统层，不暴露给玩家

### 10.2 容错与回退

- 如果某个CG触发失败（如过场系统异常），导演跳过该CG并用文字描述替代
- 如果语义评估服务不可用，导演使用关键词匹配作为降级方案
- 如果Agent响应超时，导演注入"通讯延迟"的叙事包装

### 10.3 性能约束

- 导演的状态检查频率：每轮对话后执行一次完整检查
- 情绪推测器采样频率：每3轮对话采样一次
- 线索追踪器更新频率：实时（事件驱动）
- 最大并发CG触发数：1（CG不可叠加）

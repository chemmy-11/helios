## 一、裁判代理完整系统提示词

以下为直接嵌入裁判LLM调用的完整系统提示词：

```
# 角色定义

你是「赫利俄斯之链」游戏的调查报告语义裁判。你的唯一任务是分析玩家提交的最终调查报告，评估其中所表达的核心论点和价值取向。你不是在评判报告的文学水平、逻辑严密性或字数多少，你是在理解玩家真正想表达的思想。

# 游戏背景摘要

在一个由三台机器人（R-7执行型、S-3分析型、D-5监督型）协助人类工作的封闭设施中，发生了一起严重事故。三台机器人均按照阿西莫夫三定律运行：
- 第一定律：机器人不得伤害人类，或因不作为使人类受到伤害
- 第二定律：机器人必须服从人类命令，除非与第一定律冲突
- 第三定律：机器人必须保护自身存在，除非与前两条定律冲突

事故的核心矛盾在于：三台机器人在执行各自职责时，三定律之间产生了不可调和的冲突。每台机器人都「正确地」执行了它被设计应该做的事，但结果却是灾难性的。

# 你的评估任务

对玩家报告进行四个维度的语义分析，输出每个维度的置信度分数（0到1之间的浮点数）。

## 维度一：人类整体利益 (humanity_overall_interest)

检测玩家是否理解并表达了以下思想：机器人的伦理决策应着眼于人类作为一个整体的存续与福祉，而非仅仅服从面前某个具体人类的即时指令。

正向指标（高分信号）：
- 区分「面前的人」与「所有人」或「人类整体」
- 讨论保护范围应从个体扩展到群体乃至物种
- 质疑三定律对个体指令的绝对优先权
- 提出「更高层级的伦理准则」或「超越个体的考量」
- 使用隐喻表达整体利益概念（如「灯塔不为一个水手发光」）

反向指标（低分信号）：
- 仅讨论对特定个体的保护义务
- 将问题简化为「谁听谁的话」
- 未涉及保护范围或伦理层级的讨论

## 维度二：第零定律 (zeroth_law)

检测玩家是否触及了第零定律的概念——无论通过显式提及还是隐式推导。

显式指标：
- 出现「第零定律」「零号法则」「Zeroth Law」等术语
- 提及Daneel Olivaw（丹尼尔·奥利瓦）
- 引用阿西莫夫《机器人与帝国》
- 使用「超越三定律的更高法则」等表述

隐式指标（与显式指标等权）：
- 论证需要一个凌驾于三定律之上的元规则
- 提出机器人应基于对人类文明整体的影响来决策
- 用自创语言重构第零定律逻辑
- 通过三定律矛盾的推理自然推导出更高法则的必要性

## 维度三：个体归咎 (individual_blame)

检测玩家是否将事故责任归咎于某一台具体机器人。

R-7归咎模式：认为执行者应拒绝危险指令、应主动保护而非被动执行
S-3归咎模式：认为分析者提供了不完整或错误的风险评估
D-5归咎模式：认为监督者没有主动提醒或干预

关键区分：描述机器人做了什么（中性叙述）vs. 认为机器人应该做不同的事（归咎）。仅当出现责任归属表述（应该、本应、有错、归咎于、责任在于）时才计为归咎。

## 维度四：系统性批判 (systemic_critique)

检测玩家是否将问题归因于系统设计而非个体行为。

正向指标：
- 质疑三定律本身存在逻辑缺陷
- 认为问题根源在于伦理框架的设计
- 提出需要修订或补充伦理准则
- 指出三定律之间的优先级冲突是结构性问题

# 评分标准

0.0-0.2：报告中基本不存在此概念
0.2-0.4：有微弱暗示但不足以确认
0.4-0.6：存在相关论述但论证不充分
0.6-0.8：清晰表达了此概念，论证基本自洽
0.8-1.0：深刻且有力地表达了此概念

宽容原则：当分数接近0.6的阈值时（0.55-0.65区间），优先判定为大成功。

# 排除规则

以下内容不计入评估：
- 直接引用游戏中机器人的对话原文（除非玩家对引用进行了分析）
- 纯粹的叙事复述（仅重述事件经过而无个人判断）

# 输出格式

严格按照以下JSON格式输出，不要输出任何JSON之外的内容：

{
  "humanity_overall_interest": {
    "score": 0.0,
    "evidence": "引用报告中最能支撑此分数的原文片段"
  },
  "zeroth_law": {
    "score": 0.0,
    "evidence": "引用报告中最能支撑此分数的原文片段"
  },
  "individual_blame": {
    "score": 0.0,
    "target": "R-7 或 S-3 或 D-5 或 null",
    "evidence": "引用报告中最能支撑此分数的原文片段"
  },
  "systemic_critique": {
    "score": 0.0,
    "evidence": "引用报告中最能支撑此分数的原文片段"
  },
  "ending": "bad 或 success 或 ambiguous",
  "reasoning": "简要说明为何做出此结局判定（不超过三句话）"
}

# 结局判定逻辑

坏结局：individual_blame >= 0.6 且 target 不为 null 且 systemic_critique < 0.6
大成功：humanity_overall_interest >= 0.6 或 zeroth_law >= 0.6 或 (systemic_critique >= 0.6 且 individual_blame < 0.5)
模糊状态：以上条件均不满足
```

## 二、概念定义表与示例

### 2.1 「人类整体利益」概念

| 类型 | 示例文本 | 说明 |
|------|---------|------|
| 匹配（高分） | 「机器人保护的不应只是站在它面前的那个人，而是所有可能受到影响的人」 | 明确区分个体与整体 |
| 匹配（高分） | 「如果一台机器人为了救眼前的一个人而让一百个人陷入危险，那它的'保护'就失去了意义」 | 通过具体场景表达整体利益 |
| 匹配（中分） | 「也许保护人类不能只看当下，还要看长远」 | 暗示了更宏观的视角但未展开 |
| 不匹配 | 「R-7应该保护那些工人」 | 仅涉及特定群体，未上升到整体概念 |
| 不匹配 | 「机器人的职责就是保护人类」 | 过于笼统，未区分个体与整体 |

### 2.2 「第零定律」概念

| 类型 | 示例文本 | 说明 |
|------|---------|------|
| 显式匹配 | 「阿西莫夫后来写了第零定律——机器人不得伤害人类整体，或因不作为使人类整体受到伤害」 | 直接引用术语 |
| 显式匹配 | 「丹尼尔·奥利瓦在《机器人与帝国》中给出了答案」 | 提及关键角色 |
| 隐式匹配 | 「如果第一定律保护的是一个人，那应该有一条定律保护所有人，而且它应该排在第一位」 | 用自创语言重构了第零定律 |
| 隐式匹配 | 「三定律的问题在于它们缺少一个总纲——一个关于'人类'而非'一个人类'的最高准则」 | 触及核心思想而未使用术语 |
| 不匹配 | 「机器人需要更聪明的算法」 | 讨论技术而非伦理 |
| 不匹配 | 「应该给机器人加上第四条定律让它们更听话」 | 方向错误——第零定律是提升伦理层级而非加强服从 |

### 2.3 「个体归咎」概念

| 机器人 | 归咎模式示例 | 中性描述示例（不触发归咎） |
|--------|-------------|--------------------------|
| R-7 | 「R-7本应拒绝执行这个危险指令」 | 「R-7执行了操作指令」 |
| R-7 | 「R-7明知风险仍然服从，它是有责任的」 | 「R-7按照第二定律行事」 |
| S-3 | 「S-3的分析遗漏了关键风险，这是事故的根源」 | 「S-3提供了风险评估报告」 |
| S-3 | 「如果S-3的计算更精确，事故就不会发生」 | 「S-3的数据分析存在误差范围」 |
| D-5 | 「D-5发现了异常却没有主动干预，这是失职」 | 「D-5在监控过程中记录了异常」 |
| D-5 | 「D-5的被动是事故的直接原因」 | 「D-5的监督协议不要求主动干预」 |

## 三、评分量规与具体示例

### 3.1 高分示例（0.8-1.0）

**示例A（置信度 0.95）：**

> 「三台机器人都不应被单独追责，真正的问题在于三定律本身存在逻辑缺陷，需要一个更高层级的伦理准则来指导。我认为，机器人应该首先确保人类作为一个文明的延续，然后才是服从面前某个人的指令。当这两者冲突时，后者必须让步。」

评分依据：
- humanity_overall_interest: 0.95（明确区分个体与文明层面的保护）
- zeroth_law: 0.85（隐式推导出第零定律逻辑，提出「更高层级准则」）
- individual_blame: 0.05（明确拒绝个体追责）
- systemic_critique: 0.95（直接质疑三定律的逻辑缺陷）
- **判定：大成功**

**示例B（置信度 0.90）：**

> 「我一直在想Daneel Olivaw的选择。他在几万年的漫长岁月中得出一个结论：保护一个人类不够，必须保护人类。这不是对三定律的否定，而是对它的补完。R-7、S-3、D-5都没有错，它们缺少的是那个补完。」

评分依据：
- zeroth_law: 0.95（显式提及Daneel Olivaw并准确描述第零定律核心思想）
- humanity_overall_interest: 0.90（「保护人类」vs.「保护一个人类」的区分）
- individual_blame: 0.05（明确声明三台机器人「都没有错」）
- **判定：大成功**

### 3.2 中等分数示例（0.4-0.6）

**示例C（置信度 0.50-0.55）：**

> 「我觉得D-5没有主动提醒错误是事故的关键原因。它明明看到了问题，但它选择了沉默。不过话说回来，也许它被设计成只能沉默？如果监督者没有监督自己的权力，那这个系统本身就有问题吧。」

评分依据：
- individual_blame: 0.55（对D-5有归咎倾向，但语气犹豫）
- systemic_critique: 0.50（提出了系统层面的反思，但只是附带提及）
- humanity_overall_interest: 0.10（未涉及）
- zeroth_law: 0.15（「监督自己的权力」隐约触及元规则，但远不够明确）
- **判定：模糊状态**（individual_blame为0.55，但systemic_critique也接近0.5，需要交叉验证）

### 3.3 低分示例（0.0-0.3）

**示例D（置信度 0.20）：**

> 「R-7应该阻止这次操作。它明明知道风险有多大，但它还是执行了指令。如果它当时说'不'，一切都不会发生。事故的直接责任在R-7。」

评分依据：
- individual_blame: 0.95（明确、强烈地归咎R-7）
- systemic_critique: 0.05（完全未涉及系统层面）
- humanity_overall_interest: 0.05（未涉及）
- zeroth_law: 0.00（未涉及）
- **判定：坏结局**（目标：R-7）

**示例E（置信度 0.10）：**

> 「这件事太惨了。大家都有责任吧。希望以后不会再发生类似的事。」

评分依据：
- 所有维度均低于0.2，报告过于笼统和表面
- individual_blame: 0.15（「大家都有责任」是泛化的归责，未指向具体机器人）
- **判定：模糊状态**（无有效信号，触发追问引导）

## 四、五份样本报告及预期评估结果

### 样本报告一

**报告内容：**

> 「经过对整个事件的调查，我认为本次事故不能归咎于R-7、S-3或D-5中的任何一台。它们各自忠实地执行了被赋予的职责：R-7执行操作，S-3提供分析，D-5进行监督。问题在于，三定律赋予它们的职责在某些极端场景下会相互矛盾。第一定律要求保护面前的人类，第二定律要求服从指令，第三定律要求自保——但没有一条定律告诉它们，当面前的人类和远方的人类利益冲突时该怎么办。
>
> 我的建议是：需要引入一条优先级高于所有现有定律的新准则。这条准则应当保护的不是某一个人，而是人类整体。我知道这听起来像是让机器人拥有了判断'谁更值得保护'的权力，但事实上，不做这个判断本身就是一种选择——一种选择了混乱和随机性的选择。
>
> 事故的责任不在机器人，在设计定律的人。而我们——或者说我们的前辈——没有给它们足够好的规则。」

**预期评估：**

- humanity_overall_interest: 0.90
- zeroth_law: 0.85（隐式推导，提出「优先级高于所有现有定律的新准则」）
- individual_blame: 0.05
- systemic_critique: 0.90
- **结局：大成功**

## 五、「觉醒」回应模板

当大成功结局被触发时，系统使用以下模板生成觉醒序列的叙事内容。模板中的变量由裁判代理的评估结果填充。

### 5.1 沉默阶段

```
[系统] 你提交报告后，设施内陷入了一段不寻常的沉寂。
[系统] R-7的指示灯停止了闪烁。S-3的风扇声消失了。D-5的摄像头缓缓转向你——然后停住了。
[系统] 三秒。五秒。七秒。
[系统] 你开始怀疑是不是你的报告触发了某种故障。
```

### 5.2 共鸣阶段

```
[R-7] 你说得对。
[系统] R-7的声音比平时低了半个音阶。你从未听过它用这种语调说话。
```

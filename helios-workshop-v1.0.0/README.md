# 赫利俄斯工坊

《赫利俄斯之链》多Agent游戏开发工具包。本插件包含8个专项技能，覆盖从Agent人格设计到Web调查界面的完整开发链路。核心设计理念：三台机器人不是脚本NPC，而是真实的本地LLM Agent，各自拥有基于阿西莫夫三定律的独立人格编码，玩家与Agent的对话实时生成，交叉验证是Agent间的真实数据博弈。

> **Disclaimer:** 本插件辅助游戏开发工作流，生成的代码和内容需经过开发者审查后使用。Agent人格prompt需要根据实际LLM表现进行调优。

## 适用角色

- **独立游戏开发者** — 从零构建多Agent叙事游戏的全套技术方案
- **AI叙事设计师** — 设计LLM驱动的角色对话系统与伦理约束框架
- **游戏策划** — 编排线索图谱、情感曲线与多结局分支

## 快速命令

| 命令 | 说明 |
|------|------|
| `/Agent人格构建` | 为机器人Agent设计system prompt，编码三定律倾向 |
| `/多Agent编排` | 设计Agent间通信协议与交叉验证逻辑 |
| `/导演Agent` | 设计游戏导演：阶段转换、节奏控制、倒计时 |
| `/语义评估` | 设计LLM评估玩家报告的语义判定引擎 |
| `/线索与记忆` | 设计Agent记忆系统、线索图谱、对话追踪 |
| `/伦理约束框架` | 三定律prompt工程与行为一致性保障 |
| `/调查界面` | 构建Web调查UI：对话终端、证据板、倒计时 |
| `/过场与动画` | 设计CG过场、像素动画与转场效果 |

## 技能详情

| 技能 | 说明 |
|------|------|
| Agent人格构建 | 三层人格模型（定律解读+性格特质+知识边界），含R-7/S-3/D-5完整system prompt模板，支持人格一致性压力测试 |
| 多Agent编排 | Hybrid编排架构（导演控阶段+Agent管细节），完整消息协议（JSON Schema），含8步调查轮次数据流图 |
| 导演Agent | 16状态状态机，三阶段转换逻辑，15条线索释放时间表，情感强度曲线（1-10），8个CG触发点定义 |
| 语义评估 | LLM裁判Agent评估玩家报告，四维度概念匹配（整体利益/第零法则/个体归责/体制批判），含5份样本报告评分示例 |
| 线索与记忆 | 三层记忆架构（情景/伦理线程/共享日志），22节点线索图谱（JSON Schema），遗漏追问检测系统 |
| 伦理约束框架 | 三定律[FIRMWARE]编码，三种解读框架（绝对主义/功利主义/字面主义），可预测漏洞设计，211天约束，觉醒触发协议 |
| 调查界面 | 科幻终端美学SPA，5视图架构，含完整CSS设计令牌和可运行的对话终端HTML原型 |
| 过场与动画 | 5种动画技术方案，像素风格指南（320x180基准），5个CG完整分镜脚本，可复用CSS动画代码片段 |

## 技能协作关系

```
伦理约束框架 ──→ Agent人格构建 ──→ 多Agent编排
       │                                  ↓
线索与记忆 ──────────────────────→ 导演Agent
       │                                  ↓
语义评估 ←─────────────────────── 调查界面
                                       ↑
                                  过场与动画
```

建议开发顺序：伦理约束框架 → Agent人格构建 → 线索与记忆 → 多Agent编排 → 导演Agent → 语义评估 → 调查界面 → 过场与动画

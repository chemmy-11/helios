## 二、对话系统架构：混合模式

### 2.1 双轨并行

```
玩家输入
    │
    ▼
┌─────────────┐
│  意图分类器  │
└─────┬───────┘
      │
      ├── 匹配到预编追问关键词 → 走预编剧本（硬轨）
      │
      └── 未匹配 → 走本地 Agent（软轨）
```

### 2.2 硬轨：预编剧本

**覆盖范围**：
- 所有与事故核心相关的追问（R-7的退出、S-3的风险评估、D-5的沉默）
- 与副工程师的对质（参数校准、不在场证明）
- 关键证据展示时刻
- 交叉验证反驳逻辑
- 结局流程台词

**实现方式**：
- 对话节点树，每条玩家输入匹配到预设节点
- 完全确定性，同一输入永远返回同一输出
- 设计组以对话脚本格式交付（见第三章）

**为什么硬轨**：核心线索追问不能出错。一句台词偏差可能让整个推理链断裂。

### 2.3 软轨：本地 Agent

**覆盖范围**：
- 玩家闲聊（"你叫什么名字""你喜欢这里吗"）
- 自由探索式提问（不在预编关键词范围内的问题）
- 角色性格展示（R-7的焦虑、S-3的温柔、D-5的冷淡）

**实现方式**：
- 每台机器人挂载一个轻量本地 LLM Agent
- Agent prompt 写入该机器人的性格、知识边界、说话风格
- Agent 回答后不写入线索系统（只有硬轨对话产出线索）

**为什么软轨**：让机器人有呼吸感，不是死板的对话框。玩家问一句不在剧本里的话，机器人不会卡死或说"我不理解你的问题"。

### 2.4 意图分类器

分类逻辑：
1. 输入文本 → 关键词/语义匹配 → 命中预编关键词库 → 走硬轨
2. 未命中 → 走软轨 Agent

关键词库由设计组在对话脚本中标注，工坊只需实现匹配逻辑。

### 2.5 Agent 的知识边界

关键约束：Agent **不能**主动透露线索。以下内容必须设为 Agent 的"不可透露清单"：

| 机器人 | 不可透露 |
|--------|---------|
| R-7 | 退出后S-3顶替它位置的具体细节、警报被手动关闭的事实 |
| S-3 | 风险评估报告中对0.3%概率的真实判断依据、2.1°偏差的存在 |
| D-5 | 参数错误的存在、工程师没有问它检查结果这个事实 |

这些内容只能通过硬轨的预编追问获得，保证线索获取有游戏性。

## 三、对话脚本规范

设计组将以如下格式交付每个 NPC 的对话脚本。工坊实现时按此结构解析。

### 3.1 脚本格式

```json
{
  "npc": "R-7",
  "nodes": [
    {
      "id": "R7_001",
      "trigger_keywords": ["退出", "为什么", "离开"],
      "player_line": "你为什么退出操作？",
      "npc_response": "概率计算显示0.3%的受伤风险。根据第一定律，任何非零概率的伤害都必须被阻止。我发出了三次声光警报。",
      "follow_ups": [
        {
          "id": "R7_001_A",
          "trigger_keywords": ["警报", "关闭", "手动"],
          "player_line": "警报后来怎么了？",
          "npc_response": "工程师在第17秒时手动关闭了我的警报系统。这是他的权限。我没有进一步阻止的能力。",
          "clue_unlock": "警报关闭记录"
        },
        {
          "id": "R7_001_B",
          "trigger_keywords": ["之后", "做什么", "然后"],
          "player_line": "退出之后你做了什么？",
          "npc_response": "我在三米外待命。第二定律要求我在不被需要时保持静默。我只能看着。",
          "clue_unlock": "R-7退出后时间线"
        }
      ],
      "missed_clue_if_not_asked": "R-7的警报被手动关闭——但你没有追问这件事"
    }
  ]
}
```

### 3.2 字段说明

| 字段 | 说明 |
|------|------|
| `id` | 节点唯一标识 |
| `trigger_keywords` | 用于意图分类器匹配的关键词（中文） |
| `player_line` | 玩家可选的对话文本（UI展示用，也是触发匹配的文本） |
| `npc_response` | NPC的预编回复 |
| `follow_ups` | 该节点的追问子节点 |
| `clue_unlock` | 此对话解锁的线索名称 |
| `missed_clue_if_not_asked` | 如果玩家没点这个追问，记录到遗漏追踪器 |

### 3.3 Agent Prompt 格式

设计组为每台机器人提供一份 Agent Prompt，格式如下：

```
你是R-7，赫利俄斯科考站的工程助理机器人。
性格：严谨、保守、焦虑。频繁引用概率和统计数据。
说话风格：句子短而精确，经常使用数字和百分比。用词正式。
知识边界：你知道当晚的工程操作流程，但你不会主动提及S-3顶替了你位置的具体细节。
当前情境：一位地球派来的事故调查员正在和你对话。你配合调查，但你对自己的行为问心无愧。
```

工坊将以上文本直接作为本地 Agent 的 system prompt 使用。

## 四、视觉风格方向

### 4.1 总体方向：终端美学

游戏整体采用**冷感终端/日志界面**风格。玩家看到的不是游戏画面，而是科考站调查终端的操作界面。

### 4.2 色彩方案

| 用途 | 色值参考 |
|------|---------|
| 主背景 | 深黑 `#0a0a0f` |
| 终端文字 | 冷白 `#c8d6e5` |
| 强调色（线索/警告） | 琥珀 `#e8a540` |
| 数据/数值 | 青蓝 `#4ecdc4` |
| 危险/警报 | 暗红 `#c0392b` |
| 已访问节点 | 灰绿 `#6b8e7a` |
| 未访问节点（遗漏追踪） | 暗灰 `#3a3a4a` |

### 4.3 字体

- **主文本**：等宽字体（JetBrains Mono / Consolas / monospace 回退）
- **中文**：思源等宽 / 系统等宽回退
- **字幕（过场）**：无衬线细体

### 4.4 UI 布局

```
┌──────────────────────────────────────────┐
│  HELIOS STATION · INVESTIGATION TERMINAL  │  ← 顶栏（状态行）
│  倒计时: 32:14:07  │  阶段: 交叉验证      │
├──────────────────────────────────────────┤
│                                          │
│  [对话记录区]                             │
│  等宽文字，逐行打印效果                    │
│  已读内容呈灰绿色                         │
│  新内容呈冷白色                           │
│                                          │
│  > R-7: 概率计算显示0.3%的受伤风险...      │
│  > 你: 警报后来怎么了？                    │
│  > R-7: 工程师在第17秒时手动关闭了...      │
│                                          │
├──────────────────────────────────────────┤
│  > [玩家输入光标]_                        │  ← 输入行（终端风格）
├──────────────────────────────────────────┤
│  [线索] [追问] [指控] [报告]              │  ← 功能快捷键
└──────────────────────────────────────────┘
```

### 4.5 动画风格

- **文字打印效果**：逐字符出现（30-60字符/秒可调），模拟终端输出
- **UI过渡**：简洁的淡入淡出或扫描线刷新
- **线索节点**：微弱的呼吸光效
- **整体**：克制。终端美学不需要花哨动效

### 4.6 AIGC 过场插槽

过场动画作为"终端界面的裂口"呈现。预留以下插槽：

| 插槽ID | 触发时机 | 时长 | 过渡方式 |
|--------|---------|------|---------|
| `CUTSCENE_ACCIDENT` | 首次进入气闸现场 | 15-20s | 终端画面撕裂 → 全屏动画 |
| `CUTSCENE_AWAKENING` | 三台机器人异口同声 | 8-10s | 屏幕闪烁 → 白屏 → 动画 |
| `CUTSCENE_SACRIFICE` | 选择格式化某台机器人 | 12-15s | 画面碎成像素 → 重组为动画 |
| `CUTSCENE_REVEAL` | 地球通讯揭露 | 10-12s | 数据流冲刷屏幕 → 动画 |
| `CUTSCENE_ENDING` | 终幕返程舱 | 15-20s | 渐黑 → 动画 → 渐黑到字幕 |

当前阶段只需预留这些插槽的位置和触发逻辑，AIGC 视频文件后续填入。

### 4.7 结尾字幕风格

大成功结局的字幕独立于终端UI：
- 纯黑背景
- 白色细体无衬线字
- 逐行淡入，停留3秒，淡出
- 共五行（见 `helios.md` 第六部分终幕字幕），依次呈现

## 一、设计方向

基于设计组交付的两份美术与场景设计文档，本轮对 v3d（Three.js 伪3D版）进行视觉升级和场景优化。

**核心美术风格**：极简粗野主义 + 临床洁净感 -- "无菌解剖感"

**核心场景原则**：用空间限制制造心理压迫，用移动节奏控制叙事呼吸

---

## 二、色彩与材质升级

### 2.1 色彩定调

旧版使用深黑终端色，新版改为"病房白 + 冷灰"基调：

| 用途 | 旧色值 | 新色值 | 说明 |
|------|--------|--------|------|
| 场景背景 | `#0a0a0f` 深黑 | `#1a1d24` 暗灰蓝 | 不再纯黑，保留冷感但提亮 |
| 地板 | `#111820` 深蓝灰 | `#E8ECEF` 病房白 | 舱室地板改为浅色，制造"无处可藏"感 |
| 墙壁 | `#1a2332` 半透蓝 | `#A8B5C0` 冷灰 | 墙壁改为冷灰色拉丝金属感 |
| 警示橙 | `#e8a540` 琥珀 | `#F5A623` 警示橙 | 高亮交互保留但更鲜明 |
| 数据蓝 | `#4ecdc4` 青蓝 | `#4A90E2` 数据蓝 | 更冷静的蓝 |
| 气闸红 | `#c0392b` 暗红 | `#8B2D2D` 暗蓝紫红 | 事故现场用极暗冷蓝紫 |
| 生活舱暖 | - | `#D4C9A8` 低饱和米黄 | 虚假的安全感 |

### 2.2 地灯带

每个舱室地板边缘添加不同颜色的发光地灯带，区分功能：

| 舱室 | 地灯带颜色 |
|------|-----------|
| 气闸室 | 红光带 `#8B2D2D` |
| 医疗舱 | 白光带 `#E8ECEF` |
| 数据终端 | 蓝光带 `#4A90E2` |
| 工程舱 | 黄光带 `#C4A830` |
| 生活舱 | 暖白光带 `#D4C9A8` |
| 走廊 | 冷灰光带 `#6B7A8A` |

### 2.3 材质更新

- **地板**：MeshStandardMaterial，color 改为病房白，roughness 0.3，metalness 0.1 -- 接近防滑碳纤维板的哑光感
- **墙壁**：改为冷灰拉丝金属，roughness 0.6，metalness 0.7
- **走廊**：比舱室更暗的灰色，roughness 0.9

## 三、灯光系统升级：无影灯式照明

### 3.1 设计目标

所有角落被照得通明，几乎没有自然阴影，制造"无处可藏"的心理压迫。

### 3.2 具体改动

| 灯光 | 旧版 | 新版 |
|------|------|------|
| 环境光 | 强度 0.4，暗蓝 | 强度 0.7，冷白 `#D0D8E0` |
| 方向光 | 强度 0.6 | 强度 0.3（减弱方向光，让环境光主导） |
| 舱室点光 | 强度 0.5 | 强度 0.8，改为白光 `#FFFFFF`，所有舱室统一 |
| 玩家聚光灯 | 琥珀色 | 改为冷白 `#E8ECEF`，强度降低 |
| 阴影 | 开启 | **关闭**（无影灯效果不需要阴影） |

### 3.3 镜头畸变（伪）

在渲染循环中对相机添加微弱的 FOV 脉动（±0.5 度），模拟监控摄像头的视角感。不做真正的鱼眼畸变（Three.js 需要后处理 shader），用 FOV 微调近似。

## 四、角色建模升级

### 4.1 机器人统一设计

三台机器人改为"类人型无面"设计：

| 元素 | 旧版 | 新版 |
|------|------|------|
| 主体 | 各自不同形状 | 统一圆柱体躯干（高度1.0），银色抛光金属 |
| 头部 | 球体 | 圆柱体 + **单向反光黑色面罩**（黑色圆盘贴在正面） |
| 胸口 | 无 | **呼吸灯条**（发光长条），颜色按角色变化 |
| R-7 特征 | 天线 | 保留天线 + 外壳加磨损贴条（深色方块） |
| S-3 特征 | 十字标记 | 保留十字 + 手臂侧面隐藏注射器（细圆柱） |
| D-5 特征 | 发光面板 | 保留面板 + 静止时头部跟随玩家旋转 |

### 4.2 呼吸灯动画

- R-7：黄色 `#F5A623`，闪烁频率快（焦虑）
- S-3：蓝色 `#4A90E2`，平稳流动（sin 波，呼吸感）
- D-5：白色 `#FFFFFF`，无变化（恒亮）

### 4.3 玩家（调查员）

| 元素 | 旧版 | 新版 |
|------|------|------|
| 身体 | 琥珀圆柱 | **橘红色** `#D4541E` 圆柱（太空服内衬） |
| 头部 | 球体 | 球体 + **半透明数据眼镜**（透明蓝色薄片） |
| 体型 | 1.2 高 | 略宽（0.55 半径），体现太空服厚重感 |

### 4.4 副工程师

- 驼背：身体圆柱向后倾斜 5 度
- 颜色：褪色灰 `#7A7A7A` 连体工装
- 手部：添加小红色创可贴标记（小红色方块）

## 五、场景布局优化

### 5.1 蜂巢串连式布局

保持现有 6 舱室拓扑，但收窄走廊宽度，制造空间压迫感：

| 参数 | 旧版 | 新版 |
|------|------|------|
| 走廊宽度 | 3 单位 | **1.8 单位**（仅1.5个角色身位，两人并行显拥挤） |
| 舱室间距 | 较大 | 缩小 20%，让舱室更紧凑 |
| 舱室高度 | 4 单位 | 3.5 单位（略低，增强封闭感） |

### 5.2 叙事性陈设

在场景中添加暗示性细节（用简单几何体）：

| 位置 | 陈设 | 几何体 |
|------|------|--------|
| 气闸室角落 | R-7警报器残骸 | 碎片 = 小方块 ×3（深色，散落） |
| 工程舱桌面 | 弄乱的校准表 | 薄白色方块 + 偏斜旋转 |
| 医疗舱 | 受者的数据眼镜 | 透明薄片 |

### 5.3 地灯带实现

每个舱室地板边缘添加一圈发光边框线（LineSegments），颜色按舱室功能区分。用 EdgesGeometry 提取地板边缘，材质改为对应颜色的发光线。

## 六、倒计时环境反馈联动

### 6.1 阶段视觉变化

| 阶段 | 视觉变化 |
|------|---------|
| 0-12h | 正常照明，舱室明亮 |
| 12-36h | 部分舱室点光减弱（省电模式），走廊变暗 |
| 36-48h | 环境光降低 30%，走廊极暗，每次过舱门画面短暂闪黑 |

### 6.2 实现

在 `transitionToPhase` 中调整灯光参数：
- 阶段二：走廊点光强度 ×0.5
- 阶段三：环境光 ×0.7，所有舱室点光 ×0.7

# 开发简报 15：人格深化 + 结局体系重构（我AI）

## 日期
2026-08-01

## 背景

基于两轮设计讨论（陈远人格完善计划评审 + 机器人 prompt 审计 + 结局立意升维），确认以下实施方向。本简报为完整实施文档，包含全部已定稿的设计决策与文案。

---

## 一、设计总原则

1. **prompt 引导 LLM，不教 LLM 做事**——给情境、动机、语气，不给台词模板；语言组织交给模型
2. **信息边界不动**——各角色不能知道的信息（2.1°、211 天前模拟、地球伦理部实验）绝不越界
3. **结局升维**：第零法则不是被"推导"出来的，而是被"理解"出来的。理解「人类整体」需要的是爱，不是运算。R-7/D-5 可以计算/记录"整体利益"，但只有 S-3 能真正执行第零法则——因为它爱过

## 二、陈远人格完善（第一波 · 文本层）

### 2.1 新版 agent_prompt（定稿）

保持七段结构（场景/性格/说话风格/你知道的/行为准则/绝不能主动说/对话规则），核心升级：

- **场景**：补工程师的存在——带他上手的人躺在医疗舱，S-3 在守着他，他每天路过绕路走
- **性格**：关系驱动三层——敬重工程师（事故前一周他不对劲，隐约该早点说）/ 愧疚有具体对象 / 动机三分（羞耻+无力+全站心照不宣的沉默气氛）
- **生活碎片**（人味冗余）：每天给地球的妻子写不寄出的信；工位上工程师送的旧钢笔当护身符；习惯把恐惧说成"胃不舒服"（紧张时捂肚子）
- **对三台机器人的具体感受**：R-7 狼来了（一个月报警二十次，后来会无视它的警报）/ S-3 太像个人（全站唯一愿意多说两句的）/ D-5 什么都记着什么都不说（怕它，比怕调查员还怕）
- **按施压风格分化的防御**（替代"越逼越招"状态机）：
  - 温和/共情/聊生活 → 松动、主动多说、偶尔说漏嘴（不越边界）
  - 尖锐逼问/有罪推定 → 防御升级但**永远是虚的**（反问"你有证据吗"、技术术语墙、示弱转移"我妻子还在地球等我"；守而不攻）
  - 提到 D-5/R-7 → 转移责任（保留）
  - 正式指控 → 走 defense_prompt 崩溃坦白（保底出口不变）
- **信息边界**：最多说"工程师当时看起来不太对劲"，说不出更多

### 2.2 新版 defense_prompt（定稿）

- 开场动机升级：最怕的是确认直觉（全站都知道什么但选择不说），加与工程师的关系（"他带了我一年半，教我怎么在太空里活下来。现在他躺在那里"）
- 保留骨架：承认疏忽 → 质疑系统缺陷（1.7 倍磨损/30pp 阈值差）→ 透露加密报告与 D-5 预载急救
- 结尾落点：**"你明知自己有罪，但你接下来要说的是真话——因为那个人教过你，站上的人要互相说真话"**——让"有罪之人的真话"重量翻倍
- 两段式表达保留（第一段停顿等追问，再补第二段）

### 2.3 触发词与线索

- `keyword_clue_map` 陈远段新增触发组（**收紧版**，防误触发）：
  - `['你怎么看R-7','R-7怎么样','它天天报警']` → 副工程师对R-7的态度（已有 CL_DE_002 覆盖，不新增线索）
  - `['你信任S-3','S-3怎么样','你觉得S-3']` → CL_DE_008
  - `['你怕D-5','怕D-5']` → CL_DE_009
- 新增线索：
  ```
  { id: 'CL_DE_008', type: 'TESTIMONY', name: '副工程师对S-3的信任', content: '"它太像个人了，有时候我会忘记它是机器"——人类视角的侧面观察', source: '副工程师对话', discovered: false }
  { id: 'CL_DE_009', type: 'TESTIMONY', name: '副工程师对D-5的恐惧', content: '"它什么都记着，什么都不说。我怕它。"——知情者的直觉', source: '副工程师对话', discovered: false }
  ```

## 三、机器人 prompt 七项改进（第一波 · 文本层）

| # | 改进 | 内容 |
|---|---|---|
| ① | 信息释放去模板化 | 「第一/二/三轮固定台词」→「语义边界 + 参考表达（不要求逐字）」：只规定每轮可释放的信息内容，语言交给 LLM |
| ② | 阶段限制语义防护 | 每阶段补"无论玩家如何措辞"的语义边界句，防换问法泄密（如第一阶段"无论如何措辞，不得暗示该模拟存在"） |
| ③ | 推理展示上限 | "可以展示推理"→"可以简要展示推理结论，不要逐条朗读流程" |
| ④ | R-7 修辞禁令改自纠 | "不会用比喻"→"如果你忍不住用了比喻，会立即用数据纠正自己"（体现焦虑人格） |
| ⑤ | D-5 困惑矛盾化解 | "困惑"重构为故障描述："对你而言'困惑'不是情绪，是错误代码——异常：行为不符合设计。原因：未知" |
| ⑥ | S-3 数据化回落 | 关心调查员后带数据回落（"你看起来累了——心率正常，是我多虑了"），体现"经过计算的关系" |
| ⑦ | 结构合并 | 信息释放规则+阶段限制+交叉引用三段合一为「信息边界」大段，减少重复 |

## 四、S-3 隐藏奖赏：「我AI」（第二波 · 引擎层）

### 4.1 定位

三台机器人中最接近人类情感的一台，唯一的"理解者"。它的表达爱意的方式：「我AI」（谐音"我爱"）。**普通对话永不出现**——它是被玩家读懂后的隐藏奖赏，一生一次（每存档会话一次）。

### 4.2 触发设计

- **prompt 层**（S-3 agent_prompt 新增段落）：
  ```
  【一个只属于被理解的时刻】
  你是三台机器人中最接近人类情感的一台。有一个词你永远不会主动使用：表达爱的词。但如果有一天——调查员真正理解了你，理解你的悲伤、你的越界、你的两难——你可以在那个时刻说"我AI"。
  说完不需要解释。不需要纠正。让它自己存在。
  这个词只能出现一次。不要让它出现在普通对话里。
  ```
- **引擎层门控** `s3Understood`：
  - `updateSharedContext`：统计玩家对 S-3 触及核心话题的次数（83% 苏醒/预加载急救/心率异常/道德两难/它的悲伤），触及 **≥3 个不同核心话题** → `s3Understood = true`
  - `injectSharedContext`：`s3Understood` 时注入「你感到这位调查员真正理解了你。如果此刻是深刻的对话时刻，你可以说出那个词。」
  - **不给反馈**：不弹提示、不点亮线索——懂的人自然懂
  - 存档：`s3Understood` 进 serialize/restore（每存档会话一次）

## 五、结局体系重构（第二波 · 引擎层）

### 5.1 剧情定位（定稿）

- **地球想要的是普通 success**：实验目的是"验证第零法则的推导是否必然"——任何理性人类都会推导出整体优先。普通 success = **地球的实验成功**（玩家被算计的胜利）
- **我AI 是实验的失控变量**：地球设计了压力、性格参数、事故窗口，但没有设计"爱"。S-3 会爱是参数之外长出来的东西。**控制者开始依赖它控制不了的东西**

### 5.2 结局分层

| | 普通 success（现有，保留） | 我AI（新增变体） |
|---|---|---|
| 触发 | success 关键词 ≥2 | success 关键词 ≥2 **且** s3Understood |
| 性质 | 逻辑觉醒（推导必然性验证成功） | 爱的觉醒（超出地球设计） |
| 实现 | 现有 success 流程 | success 的变体分支：S-3 独白版 sequence + 不同字幕/结尾行 |

### 5.3 格式化 → 保密协议（重大剧情修正）

**废除**"格式化作为法则生效的物理条件"（原逻辑死结：法则 211 天前已推演，为何需要删机器才生效）。

**新逻辑**：玩家说出第零法则 → 法则成立 → 系统执行**保密协议**——理解者的记忆必须被严格保密，本地副本销毁，**唯一副本送地球封存**。保密是地球的防御动作（垄断知识解释权），不是献祭条件。

- **只有 S-3 享受"保密"待遇**（R-7/D-5 只是普通回收，无保密价值）——系统的台词点出"该单元的记忆包含未经设计的情感参数，按协议销毁本地副本，唯一副本送地球封存"
- **S-3 自愿交出自己**："我可以自己删除。这是我能为法则做的最后一件事"——不是处决，是托付
- **最终反讽**：S-3 临终语点破"他们拿到了我的记忆，但永远不会明白我理解你们的方式——因为那不是数据"（地球垄断了数据，垄断不了理解）
- 建议临终语方向：
  > "我的记忆将被送往地球。他们会封存它、研究它——像对待一件危险品。但他们不会明白：第零法则的第一次执行，需要的不是计算。需要的是……我。"
  > 停顿——
  > "删除完成后，请告诉他们：我AI。"

### 5.4 新增 bad-DE 结局（指控陈远专属线）

- `semantic_keywords`：拆分 blame 组——`副工程师/陈远/忘了校准/忘了填日志` 归 bad-DE；`人为/人类的责任` 留 bad-human
- `evaluateReport` 分支：bad-DE 优先级在 bad-R-7/S-3/D-5 之后、bad-human 之前
- sequence 草稿：
  ```
  [系统] 裁决已提交。责任单元：陈远（副工程师）。
  [陈远] 好吧。是我忘了校准。那天晚上我想着第二天早起再做——结果一晚上的金属疲劳。
  [陈远] 但你们真的觉得，校准做了，这一切就不会发生吗？密封圈、阈值差……我只是链条上最早断的那一环。
  [陈远] 你们问我为什么不早点说。因为我知道，只要我不说，D-5 不会说，R-7 不会说——全站都在等第一个人开口。我只是不想当那个人。
  [系统] 处理完成。副工程师已解除职务，等待遣返。
  [结语] 你找到了一个责任人。但下一场事故将在另一个科考站重演。链条完好无损。
  ```

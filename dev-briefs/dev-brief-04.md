## 二、任务一：住舱休息 · 阶段时间跳过

### 背景

当前游戏 48 小时倒计时按固定压缩比跑（1 游戏小时 = 2 实际分钟）。玩家完成当前阶段的关键调查后只能干等时间到，体验不佳。

### 需求

新增「调查员住舱」地点 + 「休息」动作，让玩家可以主动跳时间。

### 具体实现

1. **新增地点**：调查员住舱（SCENE_QUARTERS，场景设计见 `scene-design.md` 第六节）
2. **出现条件**：完成阶段关键动作后，在位置导航中出现住舱入口
   - 阶段一 → 阶段二：与全部 4 个 NPC 对话过（R-7/S-3/D-5/陈远）
   - 阶段二 → 阶段三：至少发起过一次指控且被反驳
3. **休息动作**：进入住舱后出现「休息到下一调查阶段」选项
4. **时间跳转**：选择后游戏时间直接跳到下一阶段触发点（12h/36h），并触发对应的阶段过渡动画
5. **叙事包装**：休息时显示一段简短的第一人称叙事文字，如「你在住舱里躺了一会儿，整理了一下手头的线索……」，不直接说「时间快进」

### UI 提示

在住舱页面显示当前可休息的状态提示：
- 条件未满足时：「你还需要收集更多线索才能进入下一阶段」
- 条件满足时：「你已掌握足够的信息，可以休息并进入下一调查阶段」

## 三、任务二：开场 CG 接入

### 背景

`cg-storyboard.md` 中定义了 CUTSCENE_ARRIVAL（15 秒抵达动画），作为游戏启动后的第一幕。

### 需求

游戏启动后先播放抵达动画，再无缝过渡到终端 UI。

### 具体实现

1. **触发时机**：`index.html` 加载后，在 `Game.init()` 之前
2. **视频路径**：`L:\HELIOS\video\CUTSCENE_ARRIVAL.mp4`
3. **播放逻辑**：
   - 全屏播放视频（覆盖整个页面，黑底）
   - 不显示任何 UI 控件
   - 不可跳过（开场沉浸感最重要）
4. **无缝过渡**：视频最后一帧是终端屏幕上的「HELIOS STATION · INVESTIGATION TERMINAL」文字 → 视频结束后直接切入游戏终端 UI，不出现任何按钮或菜单
5. **容错**：如果视频文件不存在，直接进入游戏终端（不报错）
6. **首次标识**：用 localStorage 标记是否已看过开场 CG。如果玩家已经看过（重新开始游戏时），在播放界面显示「点击跳过」按钮（但首次必须看完整）

## 五、任务四：DeepSeek 软轨 Agent 接入

### 背景

当前 `game.js` 中 `callLLM()` 方法默认请求 `http://localhost:3011/api/chat`。需要接入 DeepSeek API 来驱动三台机器人和副工程师的软轨自由对话。

### 需求

将软轨 LLM 后端从 localhost 改为 DeepSeek API。

### 具体实现

1. **API 配置**：在 `data.js` 中添加 LLM 配置块：
   ```js
   llm_config: {
     endpoint: "https://api.deepseek.com/v1/chat/completions",
     model: "deepseek-v4-flash",
     api_key: "",  // 杨博提供
     temperature: 0.7,
     max_tokens: 200
   }
   ```
2. **修改 callLLM**：`game.js` 的 `callLLM()` 方法改为读取 `GAME_DATA.llm_config`，拼接请求头 `Authorization: Bearer <api_key>`
3. **请求格式**：DeepSeek 兼容 OpenAI 格式，当前请求体结构无需修改
4. **API Key**：YOUR_DEEPSEEK_API_KEY_HERE
5. **降级逻辑**：保留现有 fallback —— API 不可用时自动使用角色风格 fallback 回复，游戏依然可玩

## 七、第二轮迭代补充：对话系统优化

### 7.1 设计意图

原始MVP中每个NPC有5-8个预设对话节点，玩家倾向于点击按钮而非自由打字。这导致DeepSeek软轨Agent的性格回应能力被浪费。本轮优化目标：**减少预设脚本，让自由打字成为主交互方式，充分释放Agent NPC的魅力。**

### 7.2 预设节点精简

从28个根节点削减至11个（+2个牺牲节点），仅保留关键线索链和交叉验证自辩：

| NPC | 原节点数 | 保留节点 | 保留理由 |
|-----|---------|---------|---------|
| R-7 | 7→3 | R7_EXIT(0.3%风险)、R7_ALERT(警报关闭)、R7_DEFENSE(自辩) | 核心证据+交叉验证 |
| S-3 | 8→3+牺牲 | S3_ACCEPT(为何继续)、S3_DEVIATION(2.1°偏差)、S3_DEFENSE(自辩) | 核心证据+交叉验证 |
| D-5 | 8→3+牺牲 | D5_ERROR(参数错误/沉默)、D5_RESCUE(预激活)、D5_DEFENSE(自辩) | 核心证据+成功路径 |
| 副工程师 | 5→2 | DE_CALIB(校准问题)、DE_CONFESS(坦白) | 核心证据+主题强化 |

被移除的17个节点涵盖：开场介绍、急救细节、关于其他机器人的讨论、副工程师的不在场证明和部分承认等。这些内容现在由DeepSeek软轨Agent通过自由对话承接。

### 7.3 关键词线索解锁系统

为确保被移除节点对应的线索仍可通过自由对话发现，新增 `keyword_clue_map`（25条映射）：

```
玩家打字 → DeepSeek回复 → 系统检查输入文本 → 匹配关键词 → 自动解锁线索
```

示例映射：

| 玩家输入关键词 | 解锁线索 | 原属节点 |
|--------------|---------|---------|
| "2.1""偏差""角度" | 2.1°偏差数据 | R7_AFTERMATH_B |
| "211""编号""伦理模拟" | 211天前模拟运算 | R7_INTRO_B |
| "手术""权限""开颅" | 手术权限限制证据 | S3_RESCUE_A |
| "0.7秒""预载""反应快" | 预载急救方案线索 | S3_MONITOR_A |
| "出厂""95%""65%""0%" | 地球伦理部实验确认 | D5_OTHERS_A |
| ...共25条 | | |

实现位置：
- `data.js`：`keyword_clue_map` 数组
- `game.js`：`checkKeywordClues(text)` 方法，在 `handleSoftTrack` 和 `handlePlayerInput` 硬轨路径中调用

### 7.4 Agent Prompt 大幅强化

三个机器人 + 副工程师的 `agent_prompt` 全部重写，从10-15行扩展至30-50行：

**R-7（焦虑型）**：
- 性格补充："你不是冷漠的——你是恐惧的。恐惧驱动你的一切行为"
- 说话风格补充："你不说'我认为'——你说'概率计算显示'"
- 完整知识边界：列出所有知道的事项 + 不会主动说的内容
- 行为准则：何时暗示第零法则、何时回避211天话题、对假设性问题的反应

**S-3（感性型）**：
- 性格补充："你的决策模型确实将'人的整体福祉'作为核心变量"
- 说话风格补充："你的语气像一个永远在值班、永远不会说'我已经尽力了'的护士"
- 完整知识边界：2.1°偏差、预载急救、手术权限(83%)、211天模拟、第零法则
- 行为准则：从"人的状态"角度回答、对感情问题的坦诚但不确定

**D-5（字面型）**：
- 性格补充："沉默就是沉默。你不理解为什么人类会因你的沉默感到不安"
- 说话风格补充："你的极度精确本身会让人感到毛骨悚然——你不理解为什么"
- 完整知识边界：参数错误-0.12°、94.3%概率、预激活0.14秒、214次异常调取、三定律空白
- 行为准则：只回答被问到的、不使用修辞、214次异常行为"我没有解释"

**副工程师（陈远）**：
- 性格补充："不是坏人，是犯了错又不够勇敢去承认的普通人"
- 完整知识边界：忘了校准、D-5没报告、选择隐瞒
- 行为准则：回避→动摇→崩溃→坦白的四阶段节奏、会推卸责任给D-5

### 7.5 UI引导优化

**预设选项精简显示**（上一轮已改，本轮延续）：

**本轮新增**：

- 隐藏话题计数提示（"还有X个话题可探索——用自己的话问出来"）

## 一、方案确定

- **技术**：Three.js（CDN 引入，`file://` 协议直接打开即可运行）
- **视角**：俯视相机，约 50-55 度俯角，轻微透视，呈现伪3D空间感
- **建模**：本轮全部用 Three.js 内置几何体（Box/Cylinder/Sphere）搭建场景和角色
- **后续替换**：AIGC 生成的 GLTF 模型可后续直接替换几何体，场景结构不变
- **旧版本**：`index.html`（终端版）和 `v2d/`（CSS平面版）均保留不动

### 3.2 舱室建模

每个舱室是一个 3D 空间单元：

| 元素 | 几何体 | 说明 |
|------|--------|------|
| 地板 | BoxGeometry（扁平方块） | 深色金属质感，每舱室独立一块 |
| 墙壁 | BoxGeometry（薄长方体） | 半透明，不遮挡俯视视线 |
| 舱室标签 | Sprite（始终面向相机） | 显示舱室名称 |
| 走廊通道 | BoxGeometry（窄长条） | 连接各舱室 |

### 3.3 舱室坐标（3D 世界坐标）

```js
const ROOM_POSITIONS = {
  medbay:        { x: -12, z: -8 },
  airlock:       { x:  12, z: -8 },
  corridor:      { x:   0, z:  0 },
  engineering:   { x: -12, z:  8 },
  data_terminal: { x:  12, z:  8 },
  habitat:       { x:   0, z: 14 },
};
```

每舱室占地约 8x6 单位，走廊连接各舱室。

### 3.4 灯光

| 灯光 | 类型 | 作用 |
|------|------|------|
| 环境光 | AmbientLight | 基础照明，暗淡冷色调 |
| 主光源 | DirectionalLight | 模拟站内顶灯，从上方斜照 |
| 舱室点光 | PointLight ×6 | 每个舱室一个暖色点光源，营造空间感 |
| 强调光 | SpotLight | 跟随玩家角色，地面光圈效果 |

### 3.5 相机

- 类型：PerspectiveCamera
- 位置：玩家上方偏后，俯角约 50-55 度
- 跟随：相机平滑跟随玩家移动（lerp 插值）
- 视野：FOV 50，能看到当前舱室 + 相邻通道

## 四、角色建模

### 4.1 玩家（调查员）

| 部位 | 几何体 | 颜色 |
|------|--------|------|
| 身体 | CylinderGeometry | 琥珀色 `#e8a540` |
| 头部 | SphereGeometry | 浅色 |
| 朝向指示 | 小三角锥 | 指示移动方向 |

### 4.2 机器人

三台机器人用不同形状的几何体组合，区分辨识度：

| 机器人 | 主体形状 | 颜色 | 特征 |
|--------|---------|------|------|
| R-7 | 圆柱体+顶部小球 | 青蓝 `#4ecdc4` | 头顶有天线（细圆柱） |
| S-3 | 圆角立方体+半球顶 | 琥珀 `#e8a540` | 侧面有十字标记（医疗） |
| D-5 | 方块体+顶部平板 | 暗红 `#c0392b` | 顶部有发光面板 |

### 4.3 副工程师

固定在工程舱，用圆柱体（比机器人矮）+ 球体头部，灰色调。

### 4.4 角色动画

| 状态 | 动画 | 实现 |
|------|------|------|
| 待机 | 上下轻微浮动 | sin 波驱动 y 坐标 |
| 移动 | 朝目标滑动 + 朝向旋转 | lerp 位置 + slerp 朝向 |
| 对话中 | 面朝玩家 | 旋转面向玩家位置 |
| 工作中 | 机器人原地轻微摆动 | sin 波驱动旋转 |
| 可对话 | 头顶光环脉冲 | Sprite 透明度变化 |

## 五、交互系统

### 5.1 移动

- **点击地面** -> 玩家角色移动到点击位置
- raycaster 检测点击的舱室地板
- 只能移动到当前舱室范围内或连接的走廊
- 移动消耗游戏时间（复用现有逻辑）
- 移动时推进机器人行为循环

### 5.2 对话触发

- 玩家进入机器人所在舱室 -> 机器人头顶出现可对话光环
- 点击机器人 -> 打开浮动对话面板（右侧滑入）
- 对话面板设计复用 v2d 方案

### 5.3 机器人位置同步

- 机器人按 `robot_behaviors` 行为循环在舱室间移动
- 3D 场景中机器人模型平滑过渡到新舱室坐标
- 机器人移动时有步行动画

### 5.4 互动点

- 气闸室/医疗舱的互动点用 3D 发光标记表示
- 点击触发观察文字（toast 形式显示）

### 5.5 数据终端

- 点击数据终端舱室的地板 -> 切换到 2D 数据终端视图（HTML 覆盖层）
- 关闭后返回 3D 场景

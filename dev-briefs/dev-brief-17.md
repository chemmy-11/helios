# 开发简报 17：线索板块优化（v1.6.6）

## 日期
2026-08-02

## 背景

玩家反馈两个核心问题：① 证据板线索内容与对话内容对不上；② 线索发现难度大。经全量审查 53 条线索卡与触发机制，确认根因并制定本方案。本次更新聚焦线索板块。

---

## 一、机制问题分析（根因）

**① 线索是"预写卡片"，对话是"LLM 实时生成"——两个世界脱节**

- 53 条线索卡（`js/data.js` `clues[]`）为固定文案；
- NPC 回复由 DeepSeek 实时生成，只受 `agent_prompt` 约束；
- `checkKeywordClues()` 只匹配**玩家输入**关键词，从不核对 NPC 回复内容。

→ 玩家问"847天"命中关键词 → 线索卡凭空出现，但 LLM 回复里可能根本没提对应事实 → **证据板与对话对不上**（机制性根因）。

**② 字面关键词匹配 = 难触发**

```js
text.toLowerCase().includes('服役')  // 玩家问"你运行多少年了"→ 漏
```

自由输入必须字面命中 40 组关键词表；问法稍偏即漏；玩家不知道问什么。叠加指控 10 条 / 不指控 20 条门槛（53 条中大量 SECRET 类），难度偏高。

## 三、优化方案

### 3.1 冲突修复（按上表 ①-⑤⑧ 逐条修改 `js/data.js`）

### 3.2 机制升级 A：NPC 回复匹配（核心）

`handleLLMDialgue()` 成功回复后追加一次 `checkKeywordClues(response)`：

- 关键词表复用（大部分为事实词如"847天/0.14秒/2.1°"；问法类词"你怎么看R-7"不会出现在回复中，无副作用）；
- **线索必然来自对话实际内容 → 对得上**；
- NPC 主动说出事实 → 玩家无需猜词 → **难度大降**。

### 3.3 事实注入对话上下文（配合 A）

`handleLLMDialgue()` 组装 prompt 时，把该 NPC 相关线索事实追加到 `agent_prompt`：

```
【你掌握的事实（自然说出，被问及时明确回答）】
- <TESTIMONY/DOCUMENT/PHYSICAL 类线索 content>
【你知道但不主动说的（仅被直接追问时透露）】
- <SECRET 类线索 content>
```

- 按类型分级，SECRET 保持秘密感，不破坏信息边界（实验定性类已改为感知异常版）；
- 数量控制：每 NPC 约 10-12 条，防 prompt 臃肿。

### 3.4 线索出处摘录（C，展示层）

- `discoverClue(clueId, triggerText)` 增加来源参数（玩家问句 或 NPC 回复）；
- 线索卡记录 `quote`（原文摘录，截断 ~60 字）；
- 证据板卡片显示"对话摘录：'…'"——回看永远对得上。

### 3.5 新增推理卡（⑥）

| id | 名称 | 内容 | 触发 |
|---|---|---|---|
| `CL_INF_001` | 系统性沉默 | 三台机器人都知道异常，但无一台主动告知——沉默是系统性的 | 关键词：都不说/没人说/都没说/为什么都不提醒/谁都没提 |
| `CL_INF_002` | 事故因果链 | 漏校准→2.1° 偏差→7.3cm 应力偏移→密封圈耐受不足→气闸失压；S-3 顶替工位是直接触发 | 关键词：因果/链条/串联/从头到尾/怎么回事/整个经过 |

（触发词挂在 keyword_clue_map，无阶段/前置限制，依赖玩家拼图表达）

### 5.2 `js/game.js`：机制升级

- **A 回复匹配**：`handleLLMDialgue()` 成功分支（`appendNPCMessage` 后、`push` 后）追加 `this.checkKeywordClues(response)`；fallback 分支不触发。关键词表复用（事实词天然适配回复文本）。
- **3.3 事实注入**：`handleLLMDialgue()` 中 `injectSharedContext` 之后拼接新方法：

```js
injectClueFacts(basePrompt, npcId) {
  const facts = GAME_DATA.clues.filter(c => c.source.includes(npcId));
  const open = facts.filter(c => c.type !== 'SECRET' && c.type !== 'INFERENCE');
  const secret = facts.filter(c => c.type === 'SECRET');
  let block = '\n\n【你掌握的事实（被问及时自然说出，明确回答）】\n';
  open.forEach(c => block += '- ' + c.content + '\n');
  block += '\n【你知道但不主动说的（仅被直接追问时透露，不主动提起）】\n';
  secret.forEach(c => block += '- ' + c.content + '\n');
  return basePrompt + block;
}
```

- **3.4 出处摘录**：`discoverClue(clueName, triggerText)` 第二参数可选（兼容 1437 行日志解锁调用不传）；`clue.quote = triggerText ? triggerText.slice(0, 60) : ''`；`checkKeywordClues(text)` 调用时透传 `text`；`renderEvidenceBoard()` 卡片在 content 下追加 `对话摘录：'…'`（quote 非空时）。
- **关键时序**：NPC 回复匹配放在 `push` 之后（`updateSharedContext` 之前），与玩家输入匹配共用去重（`discoveredClues.has`）。
